# 一条误差的旅程

本地双击 `dist/index.html` 即可使用，无需安装依赖或联网。

- 七个步骤：输入、隐藏层、输出、损失、反向、同时更新、重新计算。
- 点击连接查看梯度的链式法则，支持键盘 Tab 和 Enter。
- 可修改输入、目标、六个初始权重与学习率；每次都从实验台所示初始参数计算一次更新。
- “试试 η = 20”展示步长过大使损失上升；“关闭节点 1”展示 ReLU 对梯度的截断。
- 页面采用无偏置网络，输出层也使用 ReLU。在 0 处采用子梯度 0。

运行数值复核：`node verify.cjs`。

`dist/network.js` 是计算模型，`dist/ui.js` 是交互展示。显示数值会四舍五入，实际计算使用 JavaScript 双精度浮点数。
