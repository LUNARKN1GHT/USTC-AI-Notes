# Cora 论文数据集说明

本次使用的数据集是 Cora 的一个论文引用网络子集。这里的每篇论文都有**内容特征、引用关系和研究方向标签**。我们将使用前两者来预测论文的研究方向标签。

对这个任务进行建模，并对应到图学习任务，我们有：

| 数据集中的元素       | 图学习内容 |
| -------------------- | ---------- |
| 一篇论文             | 一个节点   |
| 论文之间的引用       | 一条边     |
| 论文中出现了哪些词   | 节点特征   |
| 论文属于哪个研究方向 | 分类标签   |

## 下载与放置

从 [LINQS 下载 Cora（cora.tgz）](https://linqs-data.soe.ucsc.edu/public/lbc/cora.tgz)，将压缩包解到实验七目录，使 `cora/cora.content` 和 `cora/cora.cites` 位于 notebook 旁的 `cora/` 下。 压缩包中的 `cora/README` 有原始数据说明。使用数据时请注明来源，参见 [LINQS 数据目录](https://linqs.org/datasets/)。

数据共有 2708 篇论文，每篇 1433 维特征，分为七类。`cora/` 下的两个数据文件可以直接用 VS Code 查看：

- `cora.content`：记录论文自身的信息。每行记录为：论文ID、1433个特征、类别
- `cora.cites`: 记录论文之间的引用。每行两个数 `X1 X2`，其含义为 论文 `X2` 引用了论文 `X1`，方向为 `X2 to X1`。这里的数字即为上述的论文ID。

> 虽然论文的引用是存在方向性的，但在本次实验中，我们直接将这里的边构建为无向边，简化一下模型和计算量。
