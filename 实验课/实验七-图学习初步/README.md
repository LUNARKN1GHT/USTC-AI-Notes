## 实验约定

固定训练池每类 20 个节点，共 140；验证 500；测试 2,068。标签数量实验只从该训练池取嵌套前缀，未启用节点仍可参与图前向，不参与损失，也不转入验证或测试。全部图特征可见，训练损失只用已启用训练标签。

模型 `1433→16→7`，无偏置、ReLU、特征 dropout=0.5。MLP 使用单位传播算子，GCN 使用对称归一化图算子，均有 23,040 个可训练参数。Adam，lr=0.01，weight_decay=0.0005，200 轮；种子 42、2026。按验证准确率、较低验证损失、较早轮次选择快照。

缺失图按同一无向边乱序保留前缀，两个方向一起删除，保留所有节点与自环，每图重新归一化。模型种子之间共享图样本。研究的是缺失图上重新训练与评价，不等于固定模型的测试时删边鲁棒性。

默认 CPU，最多 4 线程；CUDA 可选但本次未验证，MPS 不列入当前运行范围。`LAB7_EPOCHS` 可缩短开发运行，改变预算必须记录，不混入正式参考比较。

当前运行会把节点划分写入 `输出_GCN/split_seed42.json`；训练与调参结果保留在 notebook 变量和普通打印输出中。保留 notebook 输出即可查看结果。

文件夹里已有的 `运行记录.json`、`验证集选定模型.pt` 和旧 `输出/` 为之前版本的备课产物，当前 Q7 不生成这些文件，也不将它们当作本次调参结果。

Q7 使用独立的 `tuning_runs`，每个新设置都重新初始化模型，原设置可复用已有 GCN 基线。不要直接改全局 CONFIG 后调用 Q4 的 `train_case`，其缓存键不包含超参数，可能复用旧结果。

## 核验与维护

```bash
python 验证参考答案.py
python 制作notebook.py
python 验证参考答案.py --execute
python 验证参考答案.py --repeat
```

数学核验包括：原始数据与连通性、固定划分、嵌套标签、双向前缀删边、度数重算、稠密／稀疏结果与参数梯度、有限差分、节点置换、MLP 退化、训练掩码、验证标签不参与更新、最佳模型恢复与 Macro-F1。

`制作notebook.py` 在修改学生版后导出配套参考表达式；随后运行验证脚本。`--execute` 用当前解释器启动本机 Jupyter 内核，完整运行参考 notebook 并保存输出，不再写入旧版最终测试记录。`--repeat` 仅用于教师复查历史固定八配置，不包含学生自选的 Q7 参数。参考版沿用当前学生版文案，不再附加旧教学环节。

本机验证使用 Unix IPC 通信，运行环境须允许本地内核套接字；不上传数据。学生通常直接使用已有 Jupyter 环境，不需要执行维护脚本。

当前学生 notebook 是唯一底稿。`python 制作notebook.py` 仅填入 `ANSWERS` 中的参考表达式、导出参考版并清空其旧输出，**不会修改学生版**。参考版也采用当前 Q1–Q7，不拼回旧模板文案。`--refresh-notes` 兼容旧命令但不再添加历史讨论。主模型、配置或划分改变后需重跑正式记录。
