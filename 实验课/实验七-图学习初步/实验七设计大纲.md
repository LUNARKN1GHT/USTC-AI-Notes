# 实验七设计大纲：图卷积网络与 Cora 论文分类

> 2026-10-31 修订：本次学习 GCN、自环与邻居聚合；注意力机制留到后续实验。课堂按 18:50–21:30、160 分钟设计。

## 一、实验定位与扩充原则

实验六研究图像空间结构，本次研究样本关系对分类的作用。任务为 Cora 固定引用网络上的半监督节点分类。

主问题：

> 当论文标签稀缺或引用关系不完整时，图传播能否帮助预测研究方向？怎样用对照实验支持判断？

原版本主要是补全模型、运行几组训练和解释结果。此次增加两项必做研究、归一化反例、双种子重复、图结构审查和分阶段解释检查。完成训练不是完成实验，必须提交假设、控制条件、数值证据、解释和局限。

扩充的是学生的判断与核验工作。CPU 训练只需几十秒，不用增加轮数或依赖长时间等待填满课时。160 分钟是教学预算，需要课堂记录校准，不能承诺所有学生恰好在 21:30 完成。

## 二、学习目标

1. 将论文、引用关系、词特征和类别对应到图数据与张量，区分字符串 ID 和连续下标。
2. 用实际计数区分无孤立节点和整图连通，检查双向化、去重与自环。
3. 手算行均值和对称归一化，说明两种算子的性质以及一跳、两跳传播范围。
4. 实现两层 GCN，并用单位算子构造同参数 MLP 基线。
5. 正确使用训练标签掩码和固定验证／测试集，构造嵌套标签预算。
6. 独立设计标签数量与引用缺失对照，完整记录重复结果而不挑选有利种子。
7. 结合总体、分类别和度数分组指标解释结果，指出证据边界并设计下一步检验。

## 三、数据、图与划分

按[数据集说明](数据集说明.md)准备 `cora/cora.content` 与 `cora/cora.cites`。

| 内容       | 本地检查结果                                   |
| ---------- | ---------------------------------------------- |
| 节点与特征 | 2,708 篇论文，1,433 维二值词特征               |
| 类别       | 7 类，编码按类别名称排序固定                   |
| 原始引用   | 5,429 行，每行为“被引用者、引用者”             |
| 无向去重边 | 5,278 条；双向消息 10,556 条                   |
| 添加自环后 | 13,264 个矩阵非零项，每节点恰有一个自环        |
| 连通性     | 无孤立节点；78 个连通分量；最大分量 2,485 节点 |

特征按行归一化，全零行保持零；图矩阵行表示接收节点、列表示发送节点。无向化意味着忽略原引用方向以允许双向交换信息，是本次明确采用的建模选择。

固定划分种子 42：每类预留 20 个训练节点，共 140；剩余节点分层抽取验证 500；测试 2,068。保留全部节点与连通分量。训练和预测均使用完整图与特征，训练损失只包含已启用的训练标签。

标签数量研究仅在同一训练池内部按固定随机顺序取每类前 5、10、20 个，得到嵌套的 35、70、140 个节点。验证与测试索引不变，未启用训练池节点保持无标签，不转为验证或测试节点。

验证标签用于模型选择，测试标签在所有方案冻结后统一评价。不能把类别作为节点特征，也不能把所有节点标签用于交叉熵。结果只评价已知图中的未知类别，不声称验证了对新图或未来论文的归纳能力。

## 四、模型与对照

令 `A_hat=A+I`，`D_hat` 为其行度数，对称传播算子为：

\[
S=\hat D^{-1/2}\hat A\hat D^{-1/2}.
\]

单层计算 `H'=SHW`，两层为：

\[
Z=S\operatorname{ReLU}(SXW_0)W_1.
\]

实施结构为 `1433→16→7`，无偏置，ReLU；输入与隐藏特征 dropout 均为 0.5。最终输出 logits，使用交叉熵。

| 模型     | 传播算子   | 可训练参数 |
| -------- | ---------- | ---------: |
| MLP 基线 | 单位矩阵 I |     23,040 |
| 两层 GCN | S          |     23,040 |

两者共享网络实现、形状、同种子初值和训练预算，仅改变传播算子。图聚合无可学习的邻居权重。行均值 `D_hat^-1 A_hat` 用于小图概念对照，不称为本次标准 GCN 算子。

公共工具提供稀疏矩阵构造与乘法，学生实现每边的归一化系数和图卷积层核心逻辑。完整图不构造高维节点对张量。

统一训练：Adam，学习率 0.01，权重衰减 0.0005，200 轮，每轮一次全图更新。必做模型种子 42、2026，教师追加种子 3407 检查趋势。每轮在更新后的评估模式下重算训练和验证指标，按验证准确率、较低验证损失、较早轮次保存与恢复最佳快照。

各时段为检查点，不设置等待时间解锁代码。助教记录各节点的完成情况，辨别卡在编码、概念、对照设计还是解释；下次依据实际分布调整工作量。

### Q1：用数据纠正说法

学生解释“无孤立点所以全图连通”“引用记录双向化后非零数必为原始记录乘二加节点数”为什么不成立。教师提供图审查和绘图工具，学生必须引用计数或图支持判断。

### Q2：计算与反例

先用指定五节点小图手算均值与对称归一化，再核验稠密和按边结果。包含不等度节点与仅自环节点，检查行和、对称性和传播范围。

另要求学生自行构造一个 3–5 节点的不等度小图，用数值反驳“对称归一化后每行和都为 1”。不能仅复述指定图的检查通过；要说明反例的度数和具体一行。

### Q3–Q4：模型与公平比较

学生完成图卷积层；用 `S=I` 核验它退化为同参数全连接层，追踪维度并检查一次梯度和更新。解释先计算 XW 可以降低图传播特征宽度，以及矩阵乘法结合律适用的条件。

主基线为每类 20 标签、完整图，两种子各训练 MLP 与 GCN，共四次。相同初始化提高比较可解释性，但统一超参数不意味着各模型都达到最优。

### Q5：标签数量研究（必做）

MLP、GCN 分别使用每类 5、10、20 标签，六配置×两种子。完整图、验证测试集合、预处理、预算均固定。复用 Q4 的 20 标签结果，不重复相同训练。

必须提交：先验假设、改变与固定条件、每类计数、嵌套关系、验证均值与标准差曲线、至少两组数值、解释与局限。不能每个预算重新划分全体数据。

### Q6：引用缺失研究（必做）

固定 GCN、每类 20 标签，保留引用关系 100%、75%、50%。以无向边为单位，按同一随机乱序保留前缀；两个方向同时删除，全部节点和自环保留。固定图种子 2026，各模型种子使用同一个缺失图版本。

每张图重新计算度数与 S，再独立初始化训练，在该版本图上验证和测试。这研究“可获得的引用数据不完整”时的效果；不同于在原图训练后仅于推理时删边。

提交边数、外部孤立节点数、连通分量数、验证曲线和定量结论。另用小图指出“删掉归一化矩阵中的部分项，却沿用原图度数”的问题。性能不要求单调变化，不能丢弃不支持预期的种子。

Q4–Q6 合计八种不同配置、16 次独立训练。固定图与嵌套标签样本下的模型重复仅测量训练随机性，不包含图缺失抽样、标签抽样或划分的全部不确定性。

### Q7–Q8：评价与现场解释

21:05 后统一测试预先规定的八配置与两种子。主模型仅在完整图、20 标签设置中按验证均值选择；不按测试表现挑模型或种子。

报告准确率、Macro-F1、分类别召回率；种子 42 的两组主混淆矩阵与外部度数 1–2、3–5、≥6 的测试组数量和准确率。分组指标用于描述，不将组间差异全部归因于度数。

学生完成两项研究结论和一题指定解释。可以先个人书面回答、组内互查，助教抽样追问：测试特征与标签隔离、节点置换、未启用训练池节点、缺失图重训与推理删边。解释须引用自己的小图、数值或代码。
