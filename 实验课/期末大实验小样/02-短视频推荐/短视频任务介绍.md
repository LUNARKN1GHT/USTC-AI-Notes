# 短视频：从观看反馈预测到曝光变化分析

同一个用户面对不同视频，可能很快划走，也可能长时间观看。平台展示了什么视频，也会影响我们能够观察到哪些反馈。本任务使用 KuaiRand-Pure 的常规曝光与随机曝光日志，建立长观看反馈预测模型，并研究模型换一种曝光方式后是否仍然有效。

数据字段、预处理示例与模型公式见 [短视频数据集说明](短视频数据集.md)。通用提交与评分要求见 [大作业要求与相关规则](../../大作业要求与相关规则.md)。[返回选题入口](../../期末大实验选题说明.md)

## 任务层次

前两部分为必做，用于基础得分评定；第三部分为“建议完成”，面向追求高分的同学，难度相较前面没有显著提升。第四部分为选做，鼓励追求满分或对相关内容感兴趣的同学进一步探究，可参考所列方向，也可自行提出其他有价值的想法。评分综合考虑工作量与质量，高质量地完成前三部分已经可以获得高分。

前两层建立常规曝光下的预测实验，第三层把已确定的模型用于两种曝光数据，第四层可围绕表示、反馈目标、泛化或其他问题深入。各层复用前面的数据处理、模型与评价结果。

| 层次 | 任务 | 主要关注 |
| --- | --- | --- |
| 第一层：反馈预测建模与基线实验（必做） | 从曝光日志构造样本，完成基线训练、评价与分析 | 可用信息、时间划分与概率预测 |
| 第二层：提出假设与研究预测（必做） | 自选合理方向设计特征或模型，完成对照与分析 | 表示方法、设计理由与实验公平性 |
| 第三层：曝光变化下的泛化与诊断（建议完成） | 在常规与随机曝光上评价固定模型，分析排序、概率和分组差异 | 分布变化、评价指标与失效原因 |
| 第四层：开放探索与深入研究（选做） | 自选表示、反馈目标、数据条件、泛化或其他有价值的问题 | 问题价值、研究深度与证据质量 |

## 第一层：反馈预测建模与基线实验（必做）

完成从曝光日志到反馈预测的实验流程：根据一次曝光发生时已经可用的用户、视频或场景信息，预测是否达到数据定义的长观看条件。

1. **整理日志并明确反馈含义。** 检查时间、用户与视频标识、视频时长、反馈标签及缺失或异常记录，说明筛选和处理依据。通过统计或可视化观察样本规模、长观看比例、视频时长和用户或视频的交互数量。理解一行记录代表一次曝光，以及长观看标签与视频时长的关系。

2. **构造输入、目标与时间划分。** 明确一条预测样本的输入、标签和形状，区分曝光前可知的信息与曝光后才发生的反馈。使用较早的常规曝光日志安排训练、验证，保留后续常规与随机曝光用于评价。需要历史统计时，明确历史窗口或更新规则，保证每条样本的特征只利用当时已有记录；预处理参数从训练部分估计。

3. **建立并训练基线。** 至少包括一个简单的常数概率基线和一个可训练预测模型，例如训练集长观看率与时长逻辑回归，也可以选择其他合理基线。说明输入、目标函数、主要设置与训练方法，通过验证部分选择设置。可以复用 `starter.py` 的读取、特征和训练代码，并说明自己的适配。

4. **评价与初步分析。** 在常规曝光的固定评价数据上比较基线，结合正例比例、概率误差和预测分布解释表现。展示指标及相关曲线或案例，观察哪些样本容易预测错误，提出值得继续研究的问题。第一层可先集中分析常规曝光，第三层再系统比较两种曝光方式。

报告中保留数据处理依据、输入输出示例、基线设置与评价结果，记录时间划分、抽样规则及必要参数，供后续层次复用。

## 第二层：提出假设与研究预测（必做）

围绕一个具体问题提出假设，设计特征或模型，并与基线进行对照。以下方向供参考，也欢迎自行拟定任何合理方向。

| 方向 | 可以参考的假设或问题 |
| --- | --- |
| 用户历史 | 用户过去的活跃程度或长观看倾向是否提供额外信息？历史较少时，平滑统计是否更可靠？ |
| 视频历史与属性 | 视频过去的反馈是否有帮助？视频时长以外的曝光前属性能否改善预测？ |
| 历史窗口与时间变化 | 更长的历史是否更好？近期行为与较早行为的作用是否不同？ |
| 非线性与交互表示 | 非线性是否能利用线性模型遗漏的关系？用户与视频嵌入能否表达历史统计没有覆盖的交互？ |
| 图结构 | 用训练期用户—视频关系构造二部图，能否提供额外信息？不同边的定义或传播范围会怎样影响结果？ |
| 样本规模与训练目标 | 不同训练样本量、正负样本处理或损失设计，是否改变预测概率与排序表现？ |

根据假设选择方法，说明新增信息、特征或模型模块的作用。保持数据划分和评价样本一致，设计能够检验假设的对照；改变输入信息时，应明确区别于仅改变模型表达能力的比较。

报告指标、曲线与案例，结合不同用户、视频或历史数量的表现分析收益和失败。说明结果是否支持假设；结果不符合预期时，也应依据证据解释，并提出可以继续检验的问题。测试部分用于报告确定方案的表现，模型选择仍使用验证部分。

## 第三层：曝光变化下的泛化与诊断（建议完成）

将基线与自己研究的模型固定下来，使用后续共同日期的常规曝光和随机曝光分别评价。保持同一个模型、预处理参数、历史信息截止点或事先确定的更新规则，记录两组筛选与抽样方式。

本层既要比较指标，也要分析模型为什么可能在两组数据上表现不同。

- **比较数据与总体表现。** 查看两组样本的长观看比例，以及用户、视频、时长或历史覆盖等分布差异。结合各组的简单基线，比较自己的模型在两种曝光下保留了多少收益。
- **区分排序与概率。** 使用 ROC-AUC 等排序指标，以及 Log loss、Brier 等概率指标，观察模型能否把更可能长观看的样本排在前面、给出的概率是否与实际比例相符。可用概率分箱图比较平均预测与实际反馈，并结合样本量解释。
- **开展分组或案例诊断。** 围绕一个与假设有关的因素深入，例如历史丰富与稀少的用户、训练中见过与未见的视频，或不同时长区间。结合统计、曲线或具体记录，分析总体变化主要发生在哪里，以及哪些解释还需要进一步实验。

形成连接“数据变化—预测表现—诊断证据”的分析，讨论第二层的改进能否延续到随机曝光。两组日志上的分数描述相应曝光样本中的反馈预测表现；若进一步讨论推荐列表或上线策略的效果，需要另外定义候选集、决策与评价依据。

本层使用测试反馈作最终评价和诊断。根据诊断继续修改模型时，应另设开发与最终评价部分，并记录新增实验的数据使用方式。

## 第四层：开放探索与深入研究（选做）

可以从前面的预测或诊断继续深入，也可以围绕用户、视频、反馈、时间和关系数据提出新的问题。表示学习、行为建模、学习目标、数据条件与评价方式等都可以成为研究对象。以下列出一些参考点，也欢迎自行提出其他有价值的想法，并用合理实验检验。

| 方向 | 可以研究的问题 | 可利用的信息或方法 |
| --- | --- | --- |
| 用户与视频表示 | 用户属性、视频属性和交互历史分别提供什么信息？哪些交互关系值得建模？ | 曝光前属性、嵌入、特征交叉或其他表示方法 |
| 行为顺序与时间结构 | 行为的先后顺序是否比汇总统计更有用？近期兴趣与长期偏好怎样结合？ | 行为序列、时间间隔、窗口或衰减、序列模型 |
| 关系与自监督学习 | 用户—视频关系能否帮助学习表示？利用训练期交互构造辅助目标是否有价值？ | 二部图、图传播、对比学习或其他自监督目标 |
| 反馈目标与联合学习 | 长观看、点赞等反馈之间是什么关系？联合学习能否改善某个目标或稀疏反馈？ | 反馈标签、多任务学习、目标与损失设计 |
| 历史稀疏与冷启动 | 历史较少或首次出现的用户、视频需要怎样的预测方法？ | 平滑统计、全局回退、属性与关系信息、不同历史规模 |
| 时间与曝光变化 | 固定模型怎样应对时间或曝光方式变化？需要多少新增信息才能适应？ | 滚动更新、独立目标域开发样本、微调或数据混合 |
| 数据分布与采样 | 热门与冷门视频、不同活跃度用户的样本差异怎样影响学习和结论？ | 分组统计、采样设计、样本权重与相同条件下的对照 |
| 概率与预测可靠性 | 高置信度是否对应可靠预测？校准、排序和不同群体的表现有什么关系？ | 独立校准集、概率分箱、不确定性与分组分析 |
| 评价与决策目标 | 不同指标会偏好怎样的模型？若构造候选集或推荐决策，需要怎样的评价设计？ | 排序与概率指标；明确候选来源、可用反馈和决策规则 |
| 稳定性与效率 | 方法在不同抽样、初始化或计算预算下是否保持收益？ | 重复实验、消融、模型简化与资源统计 |

可以选择一个方向深入，也可以形成自己的研究主线。说明问题的价值、方法所需信息及其可用时间，安排与问题相匹配的基线、对照和评价，结合具体记录分析收益、代价及适用条件。研究新目标时核对输入与标签的关系，重新建立对应基线。

若使用随机曝光反馈进行训练或校准，应将相应样本与最终测试部分分开，并与采用相同信息条件的基线比较。重新估计特征、建图或采样权重时，同样需要遵守时间与评价划分。重加权或偏差修正方法还应说明权重来源及其假设。

## 报告与复现

围绕“问题与假设—数据与划分—基线与预测研究—跨曝光评价—诊断与讨论”组织报告，完整说明前两层的工作；完成第三、四层时，补充相应的跨曝光评价、研究依据与实验。说明沿用代码与自主完成的部分，保留配置、抽样清单、历史特征规则、预处理统计量、必要参数及结果生成方式。具体交付格式以通用规则为准。

评价关注设计理由、对照公平性和结论的证据。各部分均应充分展示自己的思考与分析；评分综合考虑工作量和完成质量。
