# 文本情感分析：从词频分类到少标签学习

一条电影评论可能同时包含赞扬、否定和转折，最终情感还可能依赖较远的上下文。本任务使用 IMDb 英文影评，从词频分类建立基线，围绕自己的假设研究文本表示或训练方法，再检验标注减少时模型的表现及错误变化。

数据、代码和自监督学习示例见 [影评数据集说明](影评数据集.md)。通用提交与评分要求见 [大作业要求与相关规则](../../大作业要求与相关规则.md)。[返回选题入口](../../期末大实验选题说明.md)

## 任务安排

前两部分为必做，用于基础得分评定；第三部分为“建议完成”，面向追求高分的同学，难度相较前面没有显著提升。第四部分为选做，鼓励追求满分或对相关内容感兴趣的同学进一步探究，可参考所列方向，也可自行提出其他有价值的想法。评分综合考虑工作量与质量，高质量地完成前三部分已经可以获得高分。

各环节复用同一套文本划分与模型流程；无标签语料可用于选做的表示学习和预训练研究。

| 环节 | 任务 | 主要关注 |
| --- | --- | --- |
| 一、文本处理与分类基线（必做） | 整理评论、构造特征，训练并评价分类模型 | 文本处理、分类训练与复现 |
| 二、提出假设与开展对照（必做） | 自选文本表示或训练方向，实现并比较方法 | 设计理由、控制变量与证据 |
| 三、少标签评价与语言现象诊断（建议完成） | 比较不同标注规模，分析模型收益与典型错误 | 数据需求、分组表现与机制解释 |
| 四、进一步研究表示与迁移（选做） | 利用无标签语料、预训练或其他思路深入实验 | 方法深化、迁移与资源代价 |

## 一、文本处理与分类基线（必做）

完成从原始评论到正负情感分类的流程。可以复用 `starter.py` 的读取、分词和朴素贝叶斯代码，说明自己的适配和处理依据。

1. **整理文本与划分。** 检查类别比例、文本长度、网页标记及重复情况，通过样例观察否定、转折和情感混合表达。保留原始训练与测试边界，从训练部分划出验证集，记录抽样清单和种子；可按计算条件使用固定子集。模型读取评论正文，文件名中的评分等信息仅用于核对标签。

2. **构造输入与标签。** 说明清洗、分词、词表和未知词的处理，给出单条样本与批量输入输出的形状。选择词频或其他合理特征；使用序列模型时，还需说明截断、补齐与有效位置的处理。词表及特征统计由允许使用的训练语料估计，记录是否使用了无标签评论。

3. **建立并训练基线。** 至少包括一个多数类预测基线和一个可训练分类模型，例如词袋朴素贝叶斯或线性分类器。说明模型如何利用词信息、参数如何估计，以及验证集怎样用于选择设置。保存模型与预处理参数，形成可复现的训练和评价流程。

4. **评价与初步分析。** 报告准确率、Macro-F1 等分类指标，结合混淆情况、数据规模或错分评论分析基线的能力。保留若干含否定、转折或不同长度的例子，说明输入处理可能保留或丢失的信息，为后续假设提供依据。

测试数据用于评价确定的方案，模型和训练设置使用验证数据选择。起步代码中的 Transformer 部分演示单批次更新；选择这类模型时，需要补充完整训练、选模与推理流程。

## 二、提出假设与开展对照（必做）

围绕一个具体问题提出假设，选择适合的特征、模型或训练方法，并完成对照研究。以下方向供参考，也欢迎自行拟定任何合理方向。

| 方向 | 可以参考的假设或问题 |
| --- | --- |
| 词频与短语 | 单词频率是否足够？相邻词组合能否帮助处理否定或固定表达？ |
| 词向量与语义 | 连续向量表示能否利用不同词之间的联系，改善稀疏词频特征的不足？ |
| 词序与上下文 | 平均词向量、卷积、循环网络或注意力分别保留了什么信息？词序对哪些评论更重要？ |
| 文本长度与截断 | 更多文本是否总能改善预测？开头、结尾或局部片段提供的情感信息有何差异？ |
| 词表与预处理 | 词表大小、低频词、大小写或清洗方式会影响哪些表达？保留否定词是否有帮助？ |
| 模型容量与训练 | 更大的模型是否需要更多标签？正则化、优化或其他训练设置能否改善泛化？ |

说明方法怎样对应假设，设计能够识别关键因素作用的对照。比较表示方法时尽量保持文本范围、标签和语料一致；若研究的就是截断方式或长度，则固定其他主要条件。记录额外数据、参数量与训练预算，结合这些差异解释结果。

报告指标、训练情况和具体评论，观察收益出现在哪些表达上，哪些错误仍然存在。方法可以简单，重点是形成可解释的对照。使用神经网络时应完成实际训练；使用统计模型时说明拟合与选择过程。

## 三、少标签评价与语言现象诊断（建议完成）

固定验证与测试集合，设置不同的训练标注规模，比较基线和第二环节方法。较小标注集取自较大标注集，记录各类数量和抽样方式；各方法在同一规模下使用相同标签，训练设置通过验证部分确定。

- **比较数据需求。** 用表格或曲线展示标注量与分类表现的关系，分析第二环节方法的收益在少标签时是否保持。结合容量、表示和训练现象解释趋势，必要时通过重复抽样或初始化检查明显波动。
- **明确语料使用。** 区分用于学习的标签数量与可见的文本数量。各规模可以共享一个预先固定的训练语料词表或无标签语料池，也可以只用当前子集建词表，需说明选择并保持方法间条件一致；验证和测试正文不参与词表拟合或表示学习。
- **开展语言现象诊断。** 结合自己的问题，按长度、未知词比例或可复现的语言现象分组，记录分组规则与样本量。查看否定、转折、正负混合描述等成功和失败案例，联系模型表示、截断位置及标注量变化解释错误；规则筛选的现象应结合原文核对。

本环节沿用前面的模型实现，主要改变标注规模并深化诊断。若第二环节已研究标签数量，可复用对应实验，补充方法间比较与语言现象分析。测试诊断后继续修改方法时，应另设开发与最终评价部分，记录数据使用方式。

## 四、进一步研究表示与迁移（选做）

可以利用提供的无标签评论研究表示学习，也可以围绕前面的问题选择其他方向。

| 方向 | 可以研究的问题 | 可利用的信息或方法 |
| --- | --- | --- |
| 掩码预训练与微调 | 无标签文本学到的表示能否改善情感分类，尤其是少标签情形？ | 小型编码器、掩码预测；同一结构的随机初始化与预训练对照 |
| 词向量学习 | 上下文学习的词向量是否优于随机词向量？冻结与微调有何差异？ | CBOW、Skip-gram、平均词向量分类 |
| 其他自监督目标 | 不同预测或表示学习目标学到了什么？收益与训练成本有何差别？ | 下一词预测、合理的文本对比目标或其他自拟方案 |
| 语料与迁移 | 更多无标签评论或外部表示是否有帮助？收益来自语料、模型还是训练预算？ | 无标签语料规模、外部预训练模型、冻结编码器与微调 |
| 长文本建模 | 怎样利用前后段信息并控制计算量？ | 分段编码、分层汇总、头尾组合或其他长文本策略 |
| 语言线索与稳健性 | 模型对词序、否定或无关词有多敏感？针对性变化能否检验原有解释？ | 词序干预、局部遮挡、人工核对的最小文本变化 |
| 预测可靠性 | 高置信度是否对应更可靠的分类？哪些评论适合交给人工复核？ | 独立校准部分、概率分箱、不确定性与分组分析 |
| 稳定性与效率 | 能否以更少标签、参数或时间取得相近效果？结论对抽样有多敏感？ | 重复实验、模型简化、训练时间与资源统计 |

自监督研究需要完成“预训练—迁移参数—分类训练—评价”的实际流程，并与相同分类条件下的对照比较。使用外部模型时说明来源、已知预训练数据和额外资源；涉及新文本或改写时说明构造及标签核对方式。各种扩展均需明确共同条件，以指标和案例检验假设。

## 报告与复现

围绕“问题与假设—文本与划分—基线与对照—少标签评价—语言现象与讨论”组织报告，完整说明前两部分的工作，并根据第三、四部分的完成情况补充相应的评价、诊断与探索。保留样本清单、语料使用约定、词表或分词器、训练配置、模型参数及结果生成方式，说明沿用代码和自主完成的部分。具体交付格式以通用规则为准。

评价关注设计理由、对照公平性和结论的证据。可以使用固定子集、小型模型与适合自身条件的训练预算，完整呈现自己的研究过程。
