# IMDb 文本分类与自监督学习入门

输入一段英文电影评论，判断它表达正面还是负面情感。例如 `The acting was excellent.` 可以作为正面表达的示意句，而 `I would not recommend this film.` 包含否定。实验可以从词频开始，再研究词序、上下文和预训练能带来什么。[返回选题入口](../../期末大实验选题说明.md)

必做、建议完成与选做安排见 [文本情感分析任务介绍](文本情感分析任务介绍.md)：前两部分完成分类基线与自主对照，第三部分建议研究少标签表现及语言现象；完整自监督预训练和迁移可作为选做扩展。下面介绍数据、起步代码及相关机制。

## 数据和标签

原始文件 `data/aclImdb_v1.tar.gz` 约 84 MB，可直接读取。训练集和测试集涉及的电影互不重叠。

| 包内目录                           | 内容                   | 可以怎样使用                   |
| ---------------------------------- | ---------------------- | ------------------------------ |
| `aclImdb/train/pos/`、`train/neg/` | 各 12,500 条有标签评论 | 训练分类器，并从中划出验证部分 |
| `aclImdb/test/pos/`、`test/neg/`   | 各 12,500 条有标签评论 | 最终评估分类效果               |
| `aclImdb/train/unsup/`             | 50,000 条无标签评论    | 学习词向量或进行语言模型预训练 |
| `aclImdb/README`                   | 原始说明与引用信息     | 核对数据来源和文件约定         |

每个 `.txt` 文件是一条评论，目录给出情感标签。文件名中也包含原始评分，模型输入只读取正文，评分等元信息用于核对标签。正文长度不一，可能包含 `<br />` 等网页标记。[作者发布页](https://ai.stanford.edu/~amaas/data/sentiment/)

## 任务与实验路线

前两部分为必做，第三部分为建议完成，各环节沿用同一套数据划分与分类流程，在第三部分的少标签研究中改变可用标签数量。

| 环节       | 可以完成的工作                                            | 可用于分析的结果                             |
| ---------- | --------------------------------------------------------- | -------------------------------------------- |
| 分类建模（必做） | 整理评论与划分，构造特征，训练多数类参照之外的分类基线 | 预处理依据、分类指标与初步错误分析 |
| 自主对照（必做） | 围绕文本表示或训练假设，实现并比较方法 | 控制变量的指标、曲线与评论案例 |
| 少标签评价（建议完成） | 固定验证和测试集合，改变标注规模并诊断语言现象 | 标注量与表现的关系、分组结果与错误变化 |
| 表示与迁移（选做） | 利用无标签语料学习表示，或开展其他深化研究 | 预训练与随机初始化等对照、收益与代价 |

具体方向与开放性要求见任务介绍。现有起步脚本提供词频基线和单批次的神经网络更新；选择神经网络时，需要补充完整训练与选模流程。选择自监督扩展时，还需实现预训练参数向分类模型的迁移。

## 简单入门

在本材料目录运行。使用 NumPy 和 PyTorch，默认只抽少量数据，在 CPU 上执行。

```bash
python3 -m pip install -r starter_requirements.txt
python3 starter.py
```

[starter.py](starter.py) 固定随机种子，从原训练部分每类抽 500 条训练、100 条验证，从原测试部分每类抽 200 条测试，另抽 1,000 条无标签评论。第一次阅读可以依次看 `read_small_sample()`、`tokenize()` 和 `word_count_baseline()`。

1. **把文本拆成词。** 转小写，处理网页标记，用简单规则获得词列表。
2. **建立词表。** 用训练评论和无标签评论统计最常见的 4,000 个词，并加入补齐、未知词和遮蔽三个特殊词元。
3. **做一个可比较的基线。** 把评论转成词频向量，以词袋朴素贝叶斯分类。它统计各类评论中词的频率，输出多数类基线和词频分类器的验证、测试准确率。
4. **检查 Transformer 的两个训练批次。** 脚本分别执行一次分类损失和一次掩码预测损失的反向传播，打印张量形状。两种批次从相同的编码器初始化开始，这一步用于检查数据、损失和梯度如何连接。

无标签评论的标签记为 `-1`，只使用它的文字构造自监督目标。分类标签是 `0=负面`、`1=正面`。

起步词表使用训练评论和抽取的无标签评论，正式实验需记录这一语料范围。少标签比较中，明确词表是否由共享的固定训练语料池建立，区分可见文本与可用标签的数量；各方法使用相同约定，验证和测试正文不参与拟合。

## 从句子走到 Transformer

起步模型使用两层编码器，隐藏维度 64，每批 16 条评论，最多保留前 64 个词元。

| 数据                | 形状              | 含义                                    |
| ------------------- | ----------------- | --------------------------------------- |
| 词元编号 `ids`      | `(B, L)`          | 每个词变为一个整数，不足长度用 PAD 补齐 |
| 编码器输出 `hidden` | `(B, L, 64)`      | 每个位置结合上下文后的向量              |
| 分类分数            | `(B, 2)`          | 汇总有效位置的向量，预测正负情感        |
| 掩码预测分数        | `(B, L, N_vocab)` | 每个位置对词表中各个词给出分数          |

`B` 是批大小，`L` 是补齐后的长度，`N_vocab` 是词表大小。词嵌入加上位置嵌入后进入编码器；`src_key_padding_mask` 中为真的位置表示补齐位置，注意力计算会屏蔽这些键。池化时也应排除补齐位置。

### 自注意力怎样连接上下文

对一条长度为 $L$ 的评论，词嵌入与位置嵌入相加后得到 $H\in\mathbb R^{L\times d}$。在一个注意力头中，先做三个线性投影。

$$
Q=HW_Q,\qquad K=HW_K,\qquad V=HW_V,
\qquad
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.
$$

$W_Q,W_K\in\mathbb R^{d\times d_k}$，$W_V\in\mathbb R^{d\times d_v}$ 是可训练参数，$M\in\mathbb R^{L\times L}$ 是掩码。键位置 $j$ 为 PAD 时，$M_{ij}=-\infty$，其余位置取 0；softmax 沿键所在的列归一化。起步模型隐藏维度为 64、共有 4 个头，每个头的 $d_k=d_v=16$。多个头的输出拼接后再投影，编码器层中还包含残差连接、层归一化和前馈网络。

### 句向量怎样变成分类概率

设 $h_t$ 是编码器在位置 $t$ 的输出，$m_t$ 在真实词元处为 1、PAD 处为 0。起步代码按有效位置取平均，接上二分类头。

$$
z=\frac{\sum_{t=1}^{L}m_t h_t}{\sum_{t=1}^{L}m_t},
\qquad
p=\operatorname{softmax}(W_cz+b_c),
\qquad
\mathcal L_{\mathrm{cls}}
=-\frac{1}{B}\sum_{i=1}^{B}\log p_{i,y_i}.
$$

$z\in\mathbb R^{64}$，$W_c\in\mathbb R^{2\times64}$，$b_c\in\mathbb R^2$；$p_{i,y_i}$ 是第 $i$ 条评论对真实标签 $y_i\in\{0,1\}$ 的预测概率。代码中的 `pooled`、`classifier` 和第一次 `cross_entropy` 对应这三步。

下面是掩码任务中最核心的标签构造方式，完整实现见 `check_transformer_batches()`。

```python
import torch

torch.manual_seed(0)
# 0 为 PAD，1 为未知词，2 为 MASK，普通词从 3 开始。
ids = torch.tensor([[3, 4, 5, 6, 7, 8, 0, 0]])
chosen = (torch.rand(ids.shape) < 0.15) & (ids >= 3)
targets = ids.clone()
targets[~chosen] = -100
masked_ids = ids.clone()
masked_ids[chosen] = 2
# 模型读取 masked_ids；交叉熵只计算 targets 中非 -100 的位置。
print(masked_ids, targets)
```

令 $\mathcal M$ 为一个批次中被选中的评论与位置的集合，$\widetilde x_i$ 为替换了部分词元的评论。掩码预测用原始词元作为监督目标。

$$
\mathcal L_{\mathrm{MLM}}
=-\frac{1}{|\mathcal M|}
\sum_{(i,t)\in\mathcal M}
\log p_\theta(x_{i,t}\mid\widetilde x_i).
$$

$\theta$ 包含编码器和词表预测头的参数。起步代码从已知普通词中随机选择约 15% 的位置，全部替换为 MASK，并以 `ignore_index=-100` 排除其余位置。预训练完成后，把编码器参数交给分类模型，分类头单独初始化，再用分类标签微调。

可以先做两个实现检查。在关闭 dropout 后给句尾追加 PAD，原有词元的表示和池化分类结果应保持一致；检查掩码损失时，只有 $\mathcal M$ 内的位置直接贡献词表交叉熵。这两个检查分别对应注意力掩码和损失掩码。

## 怎样发展成自己的实验

选择神经网络分类时，先把单批次步骤扩展为遍历数据的训练循环，在验证集上选择设置和模型，再使用固定测试集评估。前两部分可研究词频、短语、词向量或上下文表示；第三部分建议在固定评价集合上比较不同标注规模。

若选择自监督扩展，预训练只读取允许使用的训练语料和无标签语料，随后将编码器参数交给分类模型。可以固定同一编码器与分类样本，比较随机初始化和掩码预训练，观察预训练损失下降后分类是否同样改善。

词频基线读取整条评论，起步 Transformer 批次截断到前 64 个词。正式比较表示方法时，可以统一文本范围并记录计算预算。挑选几条含否定、转折或正负混合描述的错分评论，有助于解释模型行为。还可尝试 word2vec，或用因果掩码改成下一个词预测。

| 可比较的因素           | 尽量保持相同的设置                     | 适合观察的结果                           |
| ---------------------- | -------------------------------------- | ---------------------------------------- |
| 随机初始化与掩码预训练 | 编码器结构、分类样本、微调预算、测试集 | 准确率，以及少量标签时的差距             |
| 有无位置嵌入           | 词表、截断长度和训练预算               | 含词序、否定和转折的错误是否变化         |
| 开头截断与头尾拼接     | 输入词元总数和模型结构                 | 丢弃信息的比例、错分评论类型             |
| 不同标签数量           | 同一测试集；较小训练样本可取自较大样本 | 标注量与准确率曲线，以及不同抽样下的波动 |

如果预训练损失下降而分类结果没有改善，可以检查掩码任务是否过于简单、截断是否丢掉情感信息，以及微调是否覆盖了预训练学到的表示，再设计下一组实验。
