# MiniGrid 网格导航入门

智能体在格子地图中转向、前进，目标是走到目标格。FourRooms 的地图由四个相连房间组成，起点、朝向和目标会随回合变化。智能体每次只能看到面前一小块区域，可以根据当前观测或历史选择动作。[返回选题入口](../../期末大实验选题说明.md)

必做、建议完成与选做安排见 [网格导航任务介绍](网格导航任务介绍.md)：前两部分建立模仿基线并围绕自己的假设开展对照，第三部分建议完成闭环导航评价与轨迹诊断。下面介绍数据和起步代码，并为规划、强化学习等选做方向提供公式。

## 先理解一个回合

本地 `data/fourrooms-expert-v0.hdf5` 约 14.6 MB，包含 590 个专家回合、10,010 步动作。一个回合从环境重置开始，到到达目标或达到步数上限结束。设这个回合执行了 `T` 步。

| 回合中的字段                  | 形状             | 含义                                   |
| ----------------------------- | ---------------- | -------------------------------------- |
| `observations/image`          | `(T+1, 7, 7, 3)` | 初始观测和每步后的局部观测             |
| `observations/direction`      | `(T+1,)`         | 朝向，0/1/2/3 对应东/南/西/北          |
| `actions`                     | `(T,)`           | 0 左转、1 右转、2 前进                 |
| `rewards`                     | `(T,)`           | 每步奖励，成功时得到随用时减少的正奖励 |
| `terminations`、`truncations` | `(T,)`           | 任务终止、达到步数上限等截断标志       |
| 回合属性 `seed`               | 一个整数         | 重建该回合地图、起点和目标的随机种子   |

数组最后三个通道分别表示对象类型、颜色和状态。例如对象编码 0 表示不可见、1 表示空地、2 表示墙、8 表示目标。这些整数是类别编号。构建模型时可以使用独热编码或嵌入，再组织成 MLP 或 CNN 的输入。文件中的格子编码可以用环境渲染成可读地图。[数据说明](https://minari.farama.org/datasets/D4RL/minigrid/fourrooms-v0/) · [环境说明](https://minigrid.farama.org/environments/minigrid/FourRoomsEnv/)

## 跑通数据与策略评估

在本材料目录运行下面的命令，代码使用 CPU。

```bash
python3 -m pip install -r starter_requirements.txt
python3 starter.py
```

[starter.py](starter.py) 先打印一个回合的形状和动作，再把完整回合划成训练和测试两部分。根据训练回合找出最多的动作，计算“始终选择这个动作”在测试轨迹上的动作准确率。随后让这个策略和随机策略各自在同样的 20 个测试场景中走完整回合，输出到达率、平均回报和平均步数。

可以按顺序阅读 `load_trajectories()`、`evaluate()` 和 `main()`。读取函数当前返回回合名、种子和动作；训练模仿模型时，需要补充局部观测，以及所选模型使用的朝向或历史。起步脚本只划分训练与测试，正式实验需预留验证回合与验证场景。`evaluate()` 展示了策略交互循环；使用记忆策略时，还需在每次环境重置后清空策略记忆。

```python
import gymnasium as gym
import minigrid

env = gym.make("MiniGrid-FourRooms-v0")
observation, info = env.reset(seed=42)
next_observation, reward, terminated, truncated, info = env.step(2)
print(observation["image"].shape, reward)
env.close()
```

每次 `step` 返回执行动作后的观测和奖励，`terminated or truncated` 为真时结束当前回合。先区分到达目标和步数耗尽，才能解释策略在哪些情况失败。

## 任务衔接与扩展路线

前两部分采用专家模仿路线，完成策略训练与对照研究；第三部分建议继续开展闭环评价。规划和交互强化学习可作为选做扩展；各路线的信息条件、数据来源与计算预算需要分别说明。

| 路线           | 从哪里开始                                                    | 一组可以解释的结果                               |
| -------------- | ------------------------------------------------------------- | ------------------------------------------------ |
| 专家模仿 | 前两部分训练局部观测到三个动作的模型，第三部分建议接入环境 | 动作准确率；开展第三部分时进一步分析到达率和失败轨迹 |
| 规划与表格学习（选做） | 固定小地图和目标，定义完整离散状态，比较价值迭代与 Q-learning | 画出价值或策略，并比较交互次数与到达步数 |
| 神经网络强化学习（选做） | 在已明确状态表示的小任务中实现 DQN，再研究观测历史 | 比较回报曲线与策略表现，研究回放或目标网络的作用 |

规划需要已知的转移与奖励模型，Q-learning 从交互样本估计动作价值。MiniGrid 的成功奖励随用时变化；若把步数预算作为任务的一部分，完整状态可写成位置、朝向和剩余步数。局部单帧未必包含决定未来所需的信息，使用观测历史或记忆模型时应说明这一限制。

## 公式与代码怎样对应

### 专家模仿的分类目标

用 `images[:-1]` 对齐 `actions`。设训练集中有 $N$ 对观测与专家动作 $(o_i,a_i)$，模型输出三个动作的概率 $\pi_\theta(a\mid o_i)$，可用交叉熵训练。

$$
\mathcal L_{\mathrm{BC}}(\theta)=-\frac{1}{N}\sum_{i=1}^{N}\log \pi_\theta(a_i\mid o_i).
$$

$\theta$ 是网络参数。代码中一批 $B$ 个观测对应 `(B, 3)` 的动作分数和 `(B,)` 的整数标签。训练后将预测动作接入 `evaluate()`，观察模型执行自己的动作以后是否仍能到达目标。

### 回报与价值迭代（选做参考）

设动作 $a_t$ 后得到奖励 $r_t$，回合在 $T$ 步结束，折扣因子为 $\gamma$。状态价值 $V(s)$ 表示从状态 $s$ 出发能够获得的回报；已知环境模型时可以反复做 Bellman 更新。

$$
\begin{aligned}
G_t&=\sum_{j=t}^{T-1}\gamma^{j-t}r_j,\\
V_{k+1}(s)&=\max_a\sum_{s'}P(s'\mid s,a)\left[R(s,a,s')+\gamma V_k(s')\right].
\end{aligned}
$$

$G_t$ 是折扣回报，$0\leq\gamma\leq1$；$P$ 是转移概率，$R$ 是该转移的期望奖励，$k$ 是迭代次数，终止状态的价值设为零。起步脚本输出的是每个回合直接相加的奖励，对应 $\gamma=1$。

### Q-learning 的样本更新（选做参考）

从交互中收集 `(状态, 动作, 奖励, 下一状态, 结束信息)`。令 $d_t=1$ 表示到达所建模任务的终止状态，$d_t=0$ 表示任务仍可继续，学习率为 $\alpha$。

$$
\begin{aligned}
y_t&=r_t+\gamma(1-d_t)\max_{a'}Q(s_{t+1},a'),\\
Q(s_t,a_t)&\leftarrow Q(s_t,a_t)+\alpha\left[y_t-Q(s_t,a_t)\right].
\end{aligned}
$$

$Q(s,a)$ 表示先执行动作 $a$ 再继续行动的预期回报。$y_t$ 是 TD 目标，方括号是 TD 误差。训练时可用 $\epsilon$-贪婪探索，评估时固定测试场景并明确是否继续随机探索。

结束交互循环与停止估计后续价值是两个判断。如果时间限制只是外部停止采样，截断后仍估计后续价值；如果步数耗尽就是任务失败，则把剩余时间纳入状态，并按有限时域终止处理。可对照环境返回的 `terminated`、`truncated` 与自己的任务定义。[Gymnasium 时间限制说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

### 可选的 DQN 目标

用网络 $Q_\theta$ 代替 Q 表，并用参数暂时固定的目标网络 $Q_{\theta^-}$ 计算目标。从经验回放池抽一个小批量 $\mathcal B$，例如采用均方 TD 损失。

$$
\begin{aligned}
y_i^-&=r_i+\gamma(1-d_i)\max_{a'}Q_{\theta^-}(s_i',a'),\\
\mathcal L_Q(\theta)&=\frac{1}{|\mathcal B|}\sum_{i\in\mathcal B}\left[Q_\theta(s_i,a_i)-\operatorname{stopgrad}(y_i^-)\right]^2.
\end{aligned}
$$

$s_i'$ 是下一状态，$\operatorname{stopgrad}$ 表示目标不参与反向传播。一次前向应输出每个可用动作的 Q 值；计算损失时只取实际执行的动作所对应的值。回放打散连续样本的相关性，目标网络减缓目标随参数更新而变化的速度。

## 对比实验与结果分析

完整要求见任务介绍。下面列出模仿研究与选做强化学习中可以比较的问题，固定其余主要条件进行实验。

| 改变的因素                 | 保持一致                         | 可以展示什么                     |
| -------------------------- | -------------------------------- | -------------------------------- |
| 单帧、连续多帧或历史注意力 | 相同专家回合、动作集合与测试场景 | 动作准确率、到达率、典型失败轨迹 |
| 探索率固定或逐渐衰减       | 相同环境、状态表示与交互预算     | 训练回报与固定评估策略的回报曲线 |
| DQN 回放或目标网络         | 相同网络、交互步数和测试种子     | 回报波动、Q 值量级与最终策略     |

到达率等于成功回合数除以评估回合数，还可比较成功回合的步数。为什么“最常见动作”可能有较高动作准确率却走不到目标？某次转错后，模型又会遇到哪些专家数据中少见的状态？这些轨迹能帮助解释指标之间的差距。

起步脚本按完整回合划分，研究陌生地图时还需按实际墙体布局分组；不同种子对应的布局关系应通过重建环境核对。专家生成轨迹时可见完整地图，记录给学习者的观测是局部视野，比较时应说明各方法可用的信息。固定测试场景用于最终评价，模型与训练设置通过验证轨迹及验证场景选择。
