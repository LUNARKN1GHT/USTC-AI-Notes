# 网格导航

这个小样用 MiniGrid 做两个实验。第一个比较专家动作预测和实际导航成功率。第二个在更小的地图上用环境奖励训练表格 Q-learning。

## 数据和运行

使用 Farama 发布的 [FourRooms 专家轨迹](https://minari.farama.org/datasets/D4RL/minigrid/fourrooms-v0/)，原文件包含 590 条完整轨迹和 10,010 步动作，约 15 MB。每一步有局部网格、朝向、动作和奖励。本实验的模仿策略只读局部网格中的对象类型。

在本目录运行。使用 Python 3.9 复现了这组结果。

```bash
python3 -m pip install -r requirements.txt
python3 run.py
```

若使用本机小样目录中已经安装的依赖，运行 `PYTHONPATH=.deps python3 run.py`。本机 CPU 复跑约 13 秒。输出为 [metrics.json](metrics.json) 和 [结果图](result.png)。若需要重新下载轨迹：

```bash
mkdir -p data
curl -fL 'https://huggingface.co/datasets/farama-minari/D4RL/resolve/main/minigrid/fourrooms-v0/data/main_data.hdf5' -o data/fourrooms-expert-v0.hdf5
```

SHA-256 为 `273bf30752d5672ee1db4c4e6ab1e8b15266b06f83415e3407661f84f27669bb`。

## FourRooms 专家模仿

用轨迹种子重建环境，核对首帧局部观测和朝向。按完整墙体布局分割数据，训练有 471 条轨迹、443 种布局，测试有 119 条轨迹、110 种布局。训练 MLP 和 CNN 预测左转、右转或前进。在测试轨迹上计算单步动作准确率，再用同一批测试种子让各策略独立走完整回合。

| 策略 | 测试轨迹动作准确率 | 交互到达率 |
| --- | ---: | ---: |
| 一直前进 | 79.7% | 1.7%（2/119） |
| MLP | 87.2% | 67.2%（80/119） |
| CNN | 87.9% | 81.5%（97/119） |

专家轨迹里前进是多数动作。模型走错一步后还会遇到专家轨迹中没有记录的状态，因此单步准确率和回合成功率回答的是两个问题。MLP 和 CNN 是单次固定种子的比较，参数量不同。

## Empty 5×5 在线强化学习

使用 MiniGrid 的随机起点版本，状态为坐标和朝向。表格 Q-learning 从 800 个交互回合的奖励学习，固定在另外 200 个起点种子上评估。

| 策略 | 到达率 | 平均回报 | 成功回合平均步数 |
| --- | ---: | ---: | ---: |
| 随机 | 77.0% | 0.528 | 34.9 |
| Q-learning | 100% | 0.965 | 3.9 |

这里的地图和目标固定，起点与朝向变化。结果反映小地图上学习策略的可行性。
