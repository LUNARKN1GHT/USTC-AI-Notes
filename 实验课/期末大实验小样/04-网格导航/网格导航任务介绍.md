# 网格导航：从专家示范到自主决策

智能体在四房间网格中转向、前进，目标是在有限步数内到达目标格。专家轨迹记录了一系列局部观测与动作，但学习到的策略执行自己的动作后，也会遇到与专家轨迹不同的情况。本任务从模仿专家开始，研究策略需要怎样的信息，并通过完整回合检验它能否完成导航。

数据格式、环境交互与公式见 [网格导航数据集说明](网格导航数据集.md)。通用提交与评分要求见 [大作业要求与相关规则](../../大作业要求与相关规则.md)。[返回选题入口](../../期末大实验选题说明.md)

## 任务安排

前两部分为必做，用于基础得分评定；第三部分为“建议完成”，面向追求高分的同学，难度相较前面没有显著提升。第四部分为选做，鼓励追求满分或对相关内容感兴趣的同学进一步探究，可参考所列方向，也可自行提出其他有价值的想法。评分综合考虑工作量与质量，高质量地完成前三部分已经可以获得高分。

各环节沿用同一套轨迹划分、输入约定与模型结果，规划和强化学习可作为进一步研究的方向。

| 环节 | 任务 | 主要关注 |
| --- | --- | --- |
| 一、轨迹建模与模仿基线（必做） | 整理专家轨迹，构造观测与动作样本，训练基线策略 | 序列处理、分类训练与复现 |
| 二、提出假设与开展对照（必做） | 自选观测表示或训练方向，实现并比较策略 | 信息条件、控制变量与证据 |
| 三、闭环导航与失败诊断（建议完成） | 让固定策略独立走完整回合，分析动作预测与任务表现的关系 | 决策后果、轨迹分析与适用条件 |
| 四、进一步研究决策与学习（选做） | 围绕记忆、交互学习、规划等问题深入实验 | 方法深化、泛化与资源代价 |

## 一、轨迹建模与模仿基线（必做）

完成从专家回合到动作预测模型的流程。可以复用 `starter.py` 中的读取和环境评价代码，并补充训练所需的观测返回、样本构造与模型训练。

1. **整理轨迹与划分。** 检查回合数量、轨迹长度、动作比例和结束情况，观察局部视野中可以看到什么。按完整回合划分训练、验证与测试，保留回合清单及环境种子；同一回合的相邻步放在同一部分。验证场景用于选择设置，测试场景用于最终评价。若研究陌生地图，进一步按实际墙体布局分组，并说明各部分的布局关系。

2. **对齐观测与动作。** 一个执行了 `T` 步的回合有 `T+1` 个观测，使用动作执行前的观测预测对应动作。明确类别编码、朝向及历史信息怎样进入模型，给出单条样本与批量输入输出的形状。局部观测的三个通道表示对象、颜色和状态，可采用独热编码、嵌入或其他合理表示。

3. **建立并训练基线。** 保留随机动作或最常见动作等简单参照，至少训练一个根据观测预测动作的模仿模型，例如 MLP 分类器。说明输入信息、动作集合、损失与优化设置，使用验证部分选择模型并保存参数。开展第三部分时，将训练好的模型接入环境，检查观测处理和动作输出是否一致。

4. **评价与初步分析。** 报告留出专家轨迹上的动作准确率、分类别表现；计划完成第三部分时，还可查看模型在验证场景中自主导航的初步情况。结合动作比例、学习曲线或轨迹，说明基线学到了什么、仍有哪些问题，为后续假设提供依据。

记录环境版本、步数上限、划分与随机种子。专家生成示范时使用的信息与策略输入分别说明；必做模型根据记录中的局部观测及自己定义的可用历史行动。

## 二、提出假设与开展对照（必做）

围绕一个具体问题提出假设，选择适合的表示或训练方法，并完成对照研究。以下方向供参考，也欢迎自行拟定任何合理方向。

| 方向 | 可以参考的假设或问题 |
| --- | --- |
| 观测编码 | 将类别编号作为类别处理，是否优于直接输入整数？颜色、对象或朝向分别提供了什么信息？ |
| 空间结构 | 保留局部格子的空间排列，是否比展平后的表示更有利于识别墙、通道或目标？ |
| 观测历史 | 当前一帧是否足够？过去的观测与动作能否帮助区分外观相似、需要不同决策的情形？ |
| 动作分布与损失 | 前进与转向的数量差异会怎样影响学习？采样或损失设计能否改善关键动作的预测？ |
| 示范数量与多样性 | 更多回合是否都同样有用？轨迹长度、起点或场景的多样性能否影响导航表现？ |
| 模型容量与训练 | 更大的模型是否改善泛化？正则化、优化或其他训练设置能否减少特定错误？ |

说明方法怎样对应假设，保持轨迹划分、可用信息与评价场景一致，并记录输入长度、参数量或训练预算的差异。使用历史时仅利用决策时已经获得的信息；训练与自主执行采用相同的历史构造规则，回合开始时重置记忆。

结合指标、训练情况和具体轨迹判断结果是否支持假设。可以选择小型模型与有限数据，重点是通过对照解释关键因素的作用。

## 三、闭环导航与失败诊断（建议完成）

固定基线与自己研究的策略，让它们在相同留出场景中从重置开始独立执行，直到到达目标或耗尽步数。后续观测来自策略实际执行的动作，每一步根据当前可用信息继续决策。核对数据与运行环境的编码、动作含义和场景重建方式，记录实际使用的场景清单。

- **比较两种评价。** 同时报告留出专家轨迹上的动作预测表现，以及环境中的到达率、平均回报和回合步数；成功回合的步数可单独统计。观察动作准确率的改进是否伴随导航改善，解释失败回合耗尽步数对总体均值的影响。
- **定位困难情景。** 结合自己的问题，按初始朝向、起终点关系、轨迹长度或其他合理因素分组，报告样本量，分析哪些情景容易失败。环境种子不同所代表的起点、目标或布局变化应依据实际环境说明。
- **开展轨迹诊断。** 展示成功和失败回合的动作或路径，寻找绕圈、反复转向、碰墙、错过通道等现象。比较基线与研究策略在同一场景中的行为，分析一次错误如何改变后续观测，以及局部视野、训练分布和历史信息可能起到的作用。

地图全局渲染可用于解释轨迹，策略的输入信息按实验约定记录。若在测试诊断后继续改进模型，应另行保留开发与最终评价场景。导航存在多条可行路径，结合实际到达情况解释与某一条专家轨迹的动作差异。

## 四、进一步研究决策与学习（选做）

可以针对前面的失败现象深入，也可以提出新的合理问题。

| 方向 | 可以研究的问题 | 可利用的信息或方法 |
| --- | --- | --- |
| 记忆与探索 | 怎样记住经过的通道、减少重复探索？更长历史是否值得额外开销？ | 多帧、循环网络、历史注意力或显式记忆 |
| 规划与表格学习 | 在可枚举的小任务中，已知模型规划与交互学习有何差异？ | 固定小地图、完整状态、价值迭代与 Q-learning |
| 神经网络强化学习 | 仅靠交互奖励能否学会导航？哪些组件影响稳定性和样本效率？ | DQN、经验回放、目标网络及组件对照 |
| 模仿与交互结合 | 专家初始化能否减少探索成本？后续交互能否修复模仿策略的错误？ | 模仿初始化、在线微调、分阶段训练 |
| 错误恢复与示范补充 | 怎样覆盖策略偏离专家后的状态？新增数据是否比同量原示范更有用？ | 明确来源的纠错示范、数据聚合与恢复轨迹 |
| 奖励与探索 | 更及时的反馈能否帮助学习？探索方式如何影响发现目标与最终路径？ | 奖励设计、探索策略；使用共同原始任务指标评价 |
| 场景泛化 | 策略能否适应不同起点、目标或实际墙体布局？ | 按场景因素或布局留出，分析难度与分布变化 |
| 可靠性与效率 | 表现对初始化、示范抽样和评价种子有多敏感？ | 重复实验、交互步数、训练时间与模型规模统计 |

比较算法时明确环境、可见信息、动作集合和数据或交互预算。采用完整状态的小任务与局部观测导航分别报告设置及结论；需要额外专家或奖励信息时，说明获取方式与成本。

## 报告与复现

围绕“问题与假设—轨迹与划分—基线与对照—闭环评价—轨迹诊断”组织报告，完整说明前两部分的工作，并根据第三、四部分的完成情况补充相应的评价、诊断与探索。保留回合与场景清单、环境版本、输入处理、训练配置、模型参数及结果生成方式，说明沿用代码和自主完成的部分。具体交付格式以通用规则为准。

评价关注设计理由、对照公平性和结论的证据。方法未带来提升时，也应结合动作预测结果与具体观测分析原因；完成闭环评价时，进一步联系实际导航轨迹解释。
