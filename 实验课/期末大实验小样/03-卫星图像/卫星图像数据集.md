# EuroSAT 卫星图像入门

EuroSAT 把卫星看到的一小块区域裁成图像，并标注该区域的地表类型。输入一张图像，输出十个类别中的一个。图像里既有颜色信息，也有道路、建筑和农田排列形成的局部结构，适合研究特征表示、CNN 和跨地区泛化。[返回选题入口](../../期末大实验选题说明.md)

## 数据是什么样的

`data/EuroSAT_RGB.zip` 有 27,000 张 64×64 的 RGB 图像，约 94.7 MB。图像所在文件夹就是标签，例如 `EuroSAT_RGB/Forest/Forest_864.jpg` 表示森林。十类如下。

| 类别名               | 含义       | 类别名      | 含义       |
| -------------------- | ---------- | ----------- | ---------- |
| AnnualCrop           | 一年生作物 | Forest      | 森林       |
| HerbaceousVegetation | 草本植被   | Highway     | 公路       |
| Industrial           | 工业区     | Pasture     | 牧场       |
| PermanentCrop        | 多年生作物 | Residential | 住宅区     |
| River                | 河流       | SeaLake     | 海洋与湖泊 |

`data/eurosat-spatial-{train,val,test}.txt` 是三个地理区域的文件名清单，分别有 16,200、5,400、5,400 张图像。训练部分用于更新模型，验证部分用于选择设置和训练轮数，测试部分用于评估新地区的表现。这些清单可以直接用于起步实验。

## 一个可以逐步完成的任务

可以把研究问题定为“颜色统计和局部空间结构，分别能帮助模型区分哪些地表类型”。例如，输入 `Forest_864.jpg`，输出十类分数，再取分数最高的类别。起步代码按下表中的类别顺序使用整数标签 0–9。

| 阶段     | 可以完成的工作                                           | 留下什么证据                   |
| -------- | -------------------------------------------------------- | ------------------------------ |
| 认识图像 | 每类查看几张图片，统计类别数与尺寸，检查地理清单是否重叠 | 样例图、各集合的类别数量       |
| 建立基线 | 跑通六维颜色统计量与线性分类器，读懂输入和交叉熵         | 验证与测试指标、错分图片       |
| 选择改进 | 选颜色直方图、纹理特征、小型 CNN 中的一种继续建模        | 说明新增表示保留了什么信息     |
| 检验解释 | 固定划分，改变一个因素，再检查变化最大的类别             | 对照表、混淆矩阵和具体错误样例 |

模型表现接近时，可以结合训练样本量、输入分辨率和误差类型提出解释，再设计下一轮对照。这条流程也可用于你自行确定的研究问题。

## 先跑通一个分类实验

在本材料目录打开终端，安装依赖并运行 [starter.py](starter.py)。代码从 ZIP 直接读取图片，默认每类取 100 张训练、20 张验证、30 张测试，总计 1,500 张，使用 CPU。

```bash
python3 -m pip install -r starter_requirements.txt
python3 starter.py
```

脚本依次完成抽样、构造特征、训练和评估。每张图片提取 RGB 各通道的均值和标准差，得到六个数。然后用一个线性层输出十类分数，以交叉熵训练，并按验证损失选择轮数。终端会输出数据形状、准确率、Macro-F1 和五张错分图像的文件名。Macro-F1 对每类分别算 F1 后取平均，可以帮助检查各类别的表现。

可以先减小训练量，也可以增加每类样本。

```bash
python3 starter.py --train-per-class 50 --epochs 30
```

## 理解图像怎样进入模型

Pillow 读取后的 RGB 图像转成 NumPy 数组，形状是 `(64, 64, 3)`。PyTorch 卷积层需要通道在前，一批图片应为 `(B, 3, 64, 64)`，其中 `B` 是批大小。下面是读取一张图并转换的例子。

```python
from zipfile import ZipFile
import numpy as np
from PIL import Image
import torch

with ZipFile("data/EuroSAT_RGB.zip") as archive:
    name = next(n for n in archive.namelist() if n.endswith(".jpg"))
    with archive.open(name) as source:
        pixels = np.array(Image.open(source).convert("RGB"))
x = torch.from_numpy(pixels).permute(2, 0, 1).float() / 255
print(x.shape)  # torch.Size([3, 64, 64])
```

若改成 CNN，可以用 `Conv2d → ReLU → Pooling → Flatten → Linear` 作为起点，并让最后一层输出 10 个分数。`starter.py` 的六维特征要相应换成图像张量。

## 公式怎样对应到代码

**特征标准化。** 颜色基线把图像转成六维向量 $z$，前三维为 RGB 均值，后三维为 RGB 标准差。第 $j$ 维按训练样本计算的均值 $\mu_j$ 和标准差 $\sigma_j$ 缩放。

$$
\widetilde z_j=\frac{z_j-\mu_j}{\max(\sigma_j,10^{-6})},\qquad j=1,\ldots,6.
$$

这对应 `starter.py` 中的 `center`、`scale` 和 `inputs`。验证、测试样本沿用同一组统计量。基线的线性层接收 `(B, 6)` 的输入，输出 `(B, 10)` 的分数，$B$ 是批大小。

**从分数到分类损失。** 对第 $i$ 张图，模型 $f_\theta$ 输出分数向量 $s_i\in\mathbb R^{10}$，其中 $\theta$ 是可学习参数。$p_{i,c}$ 表示预测为类别 $c$ 的概率，$y_i\in\{0,\ldots,9\}$ 为真实类别，$N$ 为一批样本数。

$$
p_{i,c}=\frac{\exp(s_{i,c})}{\sum_{k=0}^{9}\exp(s_{i,k})},\qquad
\mathcal L=-\frac1N\sum_{i=1}^{N}\log p_{i,y_i},\qquad s_i=f_\theta(x_i).
$$

这里 $x_i$ 可以是标准化后的颜色特征，也可以是 CNN 接收的图像张量。代码中的 `cross_entropy` 直接接收分数和整数标签，已经包含 Softmax 对应的对数概率计算。

**CNN 怎样利用局部结构。** 以步长为 1、不补零的 $3\times3$ 卷积加 ReLU 为例，某个输出位置由输入中对应的小块计算。

$$
h_{o,i,j}=\operatorname{ReLU}\!\left(b_o+\sum_{c=1}^{C_{\mathrm{in}}}\sum_{u=0}^{2}\sum_{v=0}^{2}K_{o,c,u,v}\,x_{c,i+u,j+v}\right).
$$

$x$ 是通道在前的输入，$C_{\mathrm{in}}$ 为输入通道数，首层为 3；$K$ 是形状为 $(C_{\mathrm{out}},C_{\mathrm{in}},3,3)$ 的卷积核，$b_o$ 是输出通道 $o$ 的偏置，$h_{o,i,j}$ 是该通道位置 $(i,j)$ 的特征。此例的空间尺寸由 $64\times64$ 变成 $62\times62$。同一个卷积核在不同位置共享，因而能在不同区域检测相似的局部模式。

## 可以怎样做对照

下面任选与你的问题有关的一项展开，先写明比较因素和共同设定，再查看结果。

| 比较因素             | 共同保持的条件                         | 可以观察的结果              |
| -------------------- | -------------------------------------- | --------------------------- |
| 颜色统计、纹理或 CNN | 同一划分、同一批图片与标签             | 各类 F1、常见混淆和训练开销 |
| 有无旋转或翻转增强   | 同一 CNN、样本量、训练轮数与选模方式   | 验证表现和测试类别变化      |
| 不同训练标签数量     | 固定验证与测试图像、模型和训练预算约定 | 样本数与 Macro-F1 曲线      |

训练增强只用于训练图片。若研究区域变化，可以额外从训练区域留出图片作区域内测试，并与地理留出区域分别评价，记录两组样本的来源与数量。思考哪些错误可能来自颜色相近，哪些需要道路、屋顶或田块的排列信息才能区分。

随机划分和地理划分衡量不同的泛化情景。先确定问题，再决定如何划分；需要估计的归一化参数从训练部分计算。比较模型时记录抽样清单、训练预算和错误类型，才能解释分数变化。

这些方向涉及课程中的分类、损失函数、反向传播、优化、卷积与自监督学习。原始图像由 EuroSAT 作者发布，许可说明另列出 Copernicus Sentinel 数据条款。[原始数据](https://zenodo.org/records/7711810) · [作者许可说明](https://github.com/phelber/EuroSAT#license) · [TorchGeo 地理划分](https://huggingface.co/datasets/torchgeo/eurosat/tree/68508ce)

## 论文阅读入口

- Helber 等，**EuroSAT: A Novel Dataset and Deep Learning Benchmark for Land Use and Land Cover Classification**，2019。先读数据构造、类别定义和实验设置，理解 RGB 与原始多光谱数据的区别，再说明自己使用的是哪一版数据与划分。[论文](https://arxiv.org/abs/1709.00029) · [作者给出的正式引用](https://github.com/phelber/EuroSAT#references)
- He 等，**Deep Residual Learning for Image Recognition**，2015 年预印本，CVPR 2016。作为 CNN 进阶阅读，重点看残差连接怎样帮助训练较深网络；可以在小型 CNN 中比较是否加入残差模块。[论文](https://arxiv.org/abs/1512.03385)
- Chen 等，**A Simple Framework for Contrastive Learning of Visual Representations**，ICML 2020。作为自监督拓展，关注同一图像的两种增强如何形成训练信号，以及预训练后怎样用线性分类器评估表示。迁移到本数据时，可以研究增强是否保留地表类别信息。[论文](https://proceedings.mlr.press/v119/chen20j.html)
