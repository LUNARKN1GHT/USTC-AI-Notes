# 卫星图像：从地表分类到跨地区泛化

卫星图像中的颜色、纹理和空间排列都可能帮助识别地表类型。同样是森林、农田或住宅区，不同地区的外观又可能存在差异。本任务使用 EuroSAT RGB 图像，建立地表分类模型，围绕自己的假设研究表示或训练方法，并检验模型在留出地区的表现。

数据、类别、地理划分与代码示例见 [卫星图像数据集说明](卫星图像数据集.md)。通用提交与评分要求见 [大作业要求与相关规则](../../大作业要求与相关规则.md)。[返回选题入口](../../期末大实验选题说明.md)

## 任务安排

前两部分为必做，用于基础得分评定；第三部分为“建议完成”，面向追求高分的同学，难度相较前面没有显著提升。第四部分为选做，鼓励追求满分或对相关内容感兴趣的同学进一步探究，可参考所列方向，也可自行提出其他有价值的想法。评分综合考虑工作量与质量，高质量地完成前三部分已经可以获得高分。

各环节沿用同一套图像清单、预处理约定和模型结果。计划完成第三部分的同学，应提前安排区域内与地理留出评价集合。

| 环节 | 任务 | 主要关注 |
| --- | --- | --- |
| 一、分类建模与基线实验（必做） | 整理图像和划分，构造输入，训练并评价基线 | 数据处理、分类训练与复现 |
| 二、提出假设与开展对照（必做） | 自选表示或训练方向，完成实现、比较与案例分析 | 设计理由、控制变量与证据 |
| 三、跨地区评价与错误诊断（建议完成） | 对固定模型开展区域内和留出地区评价，分析类别与错误差异 | 泛化情景、分组表现与机制解释 |
| 四、进一步研究泛化与表示（选做） | 针对问题设计改进，并检验收益、代价及适用条件 | 方法深化与稳健性 |

## 一、分类建模与基线实验（必做）

完成从图像文件到十类地表预测的实验流程。可以从提供的 `starter.py` 开始，复用其中的图像读取、颜色特征和训练代码，说明自己的适配与处理依据。

1. **整理图像与评价集合。** 检查类别、尺寸、样本数量、可读取性和重复情况，通过样例或统计观察各类图像的特点。使用提供的地理划分清单，确定训练、验证和测试图像；若计划完成第三部分，需在训练前从训练区域另行留出一组不参与训练或选模的图像，用作区域内测试。可按计算条件抽取子集，记录文件清单和各类数量，保证各集合互不重叠。

2. **构造模型输入与标签。** 明确图像或特征怎样进入模型，给出一条样本与批量输入、输出的形状。说明类别编码、像素缩放、尺寸调整和特征标准化等处理，所需统计量从训练部分估计。若使用训练增强，区分训练与评价的数据处理。

3. **建立并训练基线。** 至少包括一个简单的多数类预测基线和一个可训练分类模型，例如颜色统计特征加线性分类器，也可以选择其他合理基线。说明模型利用了哪些信息、损失函数与训练设置，使用验证集选择设置及训练轮次，并保存对应模型与预处理参数。

4. **评价与初步分析。** 使用准确率、Macro-F1 等指标评价确定的基线，展示相关曲线、分类别表现或错分样例，分析基线能够区分什么、容易混淆什么。测试数据用于报告确定方案的表现，模型与训练设置的选择使用验证数据。

报告中保留数据处理依据、划分与抽样方式、输入输出示例、基线设置和评价结果。记录随机种子及必要参数，供后续环节复用。

## 二、提出假设与开展对照（必做）

围绕一个具体问题提出假设，选择适合的特征、模型或训练方法，并完成对照研究。以下方向供参考，也欢迎自行拟定任何合理方向。

| 方向 | 可以参考的假设或问题 |
| --- | --- |
| 颜色与纹理 | 颜色分布是否已经足够？边缘、纹理或局部结构能否帮助区分颜色相近的地表？ |
| 空间结构与模型表示 | 保留像素排列的模型是否更有用？全连接、卷积或其他表示方法分别利用了什么信息？ |
| 分辨率与感受范围 | 更高分辨率是否改善分类？局部细节与较大范围的空间结构对不同类别有什么作用？ |
| 数据增强 | 旋转、翻转或颜色变化是否改善泛化？这些操作对不同地表类别是否同样合理？ |
| 标签数量与模型容量 | 训练标签减少时，哪些表示更稳定？更大的模型是否需要更多样本或不同正则化？ |
| 训练与损失设计 | 不同优化、正则化或类别处理方式，能否改善某些类别及总体表现？ |

说明所选方法怎样对应假设，设计能够识别关键因素作用的对照。比较表示时保持图像清单和标签信息一致；比较训练方法时说明共同的模型与训练预算。输入分辨率、参数量或预训练数据发生变化时，记录这些差异并结合它们解释结果。

报告指标、曲线和具体案例，观察收益出现在哪些类别、哪些错误仍然存在，以及结果是否支持假设。自行确定合理实验规模；简单方法或未带来提升的方案，也应通过实际证据说明其表现。

## 三、跨地区评价与错误诊断（建议完成）

固定基线与自己研究的模型，分别在第一环节预留的区域内测试图像、地理留出测试图像上评价。两组均使用同一模型、标签编码与评价预处理，记录各自样本来源、类别数量和规模。

本环节需要将总体结果、分类别差异与图像现象联系起来。

- **比较泛化表现。** 汇总两组的准确率、Macro-F1 等指标，观察第二环节的改进在留出地区是否仍然存在。结合类别构成或样本外观，分析两种评价情景的差别。
- **定位变化来源。** 通过逐类指标与混淆矩阵，寻找变化较大的类别和混淆关系。报告类别样本量，区分类别构成变化与同一类别识别变难等可能解释。
- **开展图像案例诊断。** 对相关类别查看成功与失败样例，比较颜色、纹理、道路或建筑排列等可观察特点。结合自己的假设分析模型可能利用或遗漏的信息，说明哪些判断有现有证据支持，哪些仍需进一步验证。

区域内测试描述训练区域中未参与学习的图像表现，地理留出测试描述另一组地区上的表现。按清单记录两组来源，并依据实际图像与指标作判断。测试诊断后继续修改方法时，应另设开发与最终评价部分，记录数据使用方式。

## 四、进一步研究泛化与表示（选做）

针对前面观察到的问题设计更深入的实验，也可以提出新的合理问题。以下方向结合图像特点、地理划分与已有课程内容，供参考。

| 方向 | 可以研究的问题 | 可利用的信息或方法 |
| --- | --- | --- |
| 增强与不变性 | 模型对方向、颜色或亮度有多敏感？哪些变化应保留类别，哪些可能损坏识别线索？ | 旋转、翻转、颜色扰动；逐项比较与类别分析 |
| 多尺度与局部结构 | 道路、田块、屋顶等结构是否需要不同观察尺度？融合多个尺度是否值得增加开销？ | 不同分辨率、局部块、感受范围或多尺度特征 |
| 少标签与迁移 | 标签较少时，已有表示能否帮助分类？收益来自表示还是额外数据与计算？ | 嵌套标签子集、已有模型的特征、冻结编码器与微调 |
| 自监督表示 | 利用训练部分的图像进行表示学习，是否改善后续分类或跨地区表现？ | 对比学习、重建等目标；随机初始化与预训练初始化对照 |
| 颜色与纹理依赖 | 某类错误主要与颜色、局部纹理还是空间排列有关？能否用针对性干预检验解释？ | 灰度、局部遮挡、图像块打乱等；同时检查干预是否改变语义 |
| 地区变化与适应 | 若有一部分新地区开发数据，怎样适应，能否改善后续留出图像的表现？ | 独立目标地区开发集；归一化、微调或表示对齐 |
| 预测可靠性 | 高分预测是否更可靠？在新地区或容易混淆的类别上是否存在系统性过度自信？ | 概率分箱、独立校准集、不确定性与分组分析 |
| 稳定性与效率 | 方法的收益在不同抽样或初始化下是否保持？能否以更少参数、样本或训练时间取得相近效果？ | 重复实验、模型简化、训练预算与资源统计 |

可以选择一个方向深入，也可以自行提出其他方案。使用外部预训练模型时说明来源、已知预训练数据及其使用方式；不同信息条件的方案应分别说明。使用留出地区的数据学习、适应或校准时，应预先安排独立开发部分，并保留最终测试数据。各种扩展均需明确共同条件，结合案例与指标检验解释。

## 报告与复现

围绕“问题与假设—数据与划分—基线与对照—跨地区评价—图像案例与讨论”组织报告，完整说明前两部分的工作；完成第三、四部分时，补充相应的跨地区评价、研究依据与实验。说明沿用代码与自主完成的部分，保留图像清单、预处理、配置、模型参数及结果生成方式。具体交付格式以通用规则为准。

评价关注设计理由、对照公平性和结论的证据。可以根据计算条件使用固定子集和小型模型，说明规模与取舍，完整呈现自己的研究过程。
