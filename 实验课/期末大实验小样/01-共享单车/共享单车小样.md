# Oslo City Bike 预测与调度小样

用真实骑行记录预测未来一小时的站点借还量，再在同一批测试日期回放行程，检验预测误差和调度效果是否一致。这里实现了基线、带邻站特征的岭回归和几种贪心规则。调度回放可作为后续强化学习环境的起点。

## 数据与运行

使用运营方发布的 2025 年 8 月整月匿名行程，共 176,415 行，原始 CSV 约 35 MiB，位于本地 `data/oslo-2025-08.csv`。`data/station-information.json` 是 2026 年 11 月 13 日下载的原始站点信息。`stations.json` 保留本小样所选站点的坐标、容量和原始快照的校验值。两项数据均来自 Oslo City Bike，采用 [NLOD 2.0](https://data.norge.no/nlod/en/2.0)。[官方历史数据与字段](https://oslobysykkel.no/en/open-data/historical) · [官方 GBFS 文档](https://oslobysykkel.no/en/open-data/realtime)

在本目录运行以下命令。`results.json` 保存数据校验值、切分、预测和回放结果，`forecast.png` 绘制测试周前两天一个站点的借还预测。已在本机 Python 3.9、NumPy 2.0.2、pandas 2.3.3、Matplotlib 3.9.4 上实跑。

```sh
python -m pip install numpy 'pandas>=2.0' matplotlib
mkdir -p data
curl -fL https://data.urbansharing.com/oslobysykkel.no/trips/v1/2025/08.csv -o data/oslo-2025-08.csv
python run.py
```

## 预测

按奥斯陆当地时间聚合借、还事件。训练、验证、测试分别为 8 月 1–19 日、20–24 日、25–31 日，第一天留给滞后特征。根据训练期借车量选 16 个有容量数据的站点。模型在每个整点预测随后一小时的两个计数，岭回归只看最近两小时和前一天同小时的计数、站点与日历特征。邻站版本额外使用三座地理最近站的历史计数均值。标准化参数来自训练期，正则强度由验证期确定。统计 05:00–次日 01:00 的预测误差，共 4,480 个测试计数。

| 模型                             | 验证 MAE |  测试 MAE | 测试工作日高峰 MAE |
| -------------------------------- | -------: | --------: | -----------------: |
| 同小时历史均值，区分工作日和周末 |    1.632 |     1.778 |              2.742 |
| 单站岭回归                       |    1.765 |     1.698 |          **2.563** |
| 岭回归 + 邻站                    |    1.737 | **1.680** |              2.575 |

邻站特征在这一周整体略有收益，单站岭回归在工作日高峰更好。历史均值在验证集上最优，三个模型的排序随时间窗口变化。可以换月份或分周重复，判断结果是否稳定。

## 调度回放

回放同一测试周的 10,128 条涉及入选站点的历史行程。站点初始库存为各自容量的一半。每个营业整点最多从一个站点向另一个站点调拨三辆车。库存贪心按与半满状态的差额选择调拨，预测贪心在同一规则里加入未来一小时的预测净借车量。岭回归在回放时只使用决策前的已完成借还计数，测试开始前一天用原始记录提供预热历史。

| 策略                 | 缺车借车失败 | 满站首次还车受阻 | 调车总量 |
| -------------------- | -----------: | ---------------: | -------: |
| 不调车               |          435 |            2,504 |        0 |
| 库存贪心             |      **114** |            2,095 |      387 |
| 历史均值 + 贪心      |          115 |        **2,055** |      391 |
| 单站岭回归 + 贪心    |          120 |            2,108 |      392 |
| 岭回归 + 邻站 + 贪心 |          117 |            2,088 |      392 |

整体 MAE 最低的预测器没有带来最少的借车失败或还车受阻。现有结果适合用来提出下一轮实验，比如统一调度预算、对高峰的预测误差单独加权、在多种初始库存下重跑。

历史数据只记录已完成的骑行。回放把这些行程作为需求情景，使用后期站点容量和设定的初始库存。站外出发和到达作为外部流入与流出，满站还车进入该站等待队列，缺车借车失败后取消配对还车。模型忽略调拨耗时、真实运营调度和用户改去别的站点的行为。回放检查每小时库存守恒和容量约束。结果描述这个仿真情景。
