#### 配置 Conda 包镜像

下载安装器和下载软件包是两件事。安装 Miniconda 后，`conda create` 和 `conda install` 仍需要访问软件仓库。中科大镜像当前主要提供 Miniconda 安装包，以及 `conda-forge`、`bioconda` 频道的动态缓存。课程只需要 `conda-forge`。

先查看当前配置文件的位置：

```bash
conda config --show-sources
```

如果已经存在 `.condarc`，建议先备份。macOS 可以运行：

```bash
cp ~/.condarc ~/.condarc.bak
```

Windows 可以在 Anaconda Prompt 中运行：

```bat
copy "%USERPROFILE%\.condarc" "%USERPROFILE%\.condarc.bak"
```

如果提示文件不存在，说明此前没有用户配置，可以继续。随后打开配置文件：

- macOS：`~/.condarc`
- Windows：`%USERPROFILE%\.condarc`

Windows 如果看不到该文件，可以先运行下面的命令生成它，再用记事本打开：

```bat
conda config --set show_channel_urls yes
notepad "%USERPROFILE%\.condarc"
```

将 `.condarc` 的内容完整替换为：

```yaml
channels:
  - nodefaults
custom_channels:
  conda-forge: https://mirrors.ustc.edu.cn/anaconda/cloud
  bioconda: https://mirrors.ustc.edu.cn/anaconda/cloud
show_channel_urls: true
```

这里使用 `nodefaults`，避免混用 Anaconda 官方 `defaults` 与 `conda-forge`。保存配置后清除旧的频道索引缓存：

```bash
conda clean -i
```

此后创建环境或安装包时，需要显式指定 `conda-forge`：

```bash
conda create -n ai-lab -c conda-forge python=3.12 jupyter ipykernel -y
```

执行时留意终端显示的频道地址。看到 `mirrors.ustc.edu.cn`，或者镜像站帮助中说明的重定向地址，说明镜像配置已经生效。

#### 镜像配置失败时恢复

先运行 `conda config --show-sources`，确认实际生效的是哪个 `.condarc`。如果配置后出现频道找不到、YAML 格式错误或依赖解析异常，可以恢复备份：

macOS：

```bash
cp ~/.condarc.bak ~/.condarc
conda clean -i
```

Windows：

```bat
copy /Y "%USERPROFILE%\.condarc.bak" "%USERPROFILE%\.condarc"
conda clean -i
```

如果此前没有备份，可以把 `.condarc` 重命名为 `.condarc.disabled`，然后重新打开终端。不要同时叠加多个来源不明的镜像配置。

### 为什么不直接使用 base 环境

`base` 是 conda 自己的基础环境。把所有课程、项目的包都装进 `base`，以后很容易出现版本冲突。每个项目使用独立环境，出现问题时可以单独重建，不影响其他项目。

## 7. Python 基础语法

### 7.1 输出、注释与变量

```python
# 井号后面是注释
course = "人工智能实验"
week = 1
temperature = 26.5
is_ready = True

print(course)
print(type(week), type(temperature), type(is_ready))
print(f"第 {week} 周：{course}")
```

常见基础类型：`int` 整数、`float` 小数、`str` 字符串、`bool` 布尔值。变量名区分大小写，不能以数字开头。

### 7.2 运算符与类型转换

```python
a = 7
b = 3

print(a + b, a - b, a * b)
print(a / b)   # 真除法
print(a // b)  # 整除
```

### 7.4 常用数据存储结构

Python 内置了多种数据结构。先根据数据的组织方式选择结构，再考虑具体操作：

| 结构         | 写法                 | 特点                     | 常见用途           |
| ------------ | -------------------- | ------------------------ | ------------------ |
| 列表 `list`  | `[88, 72, 95]`       | 有顺序、可修改、允许重复 | 一组成绩、订单列表 |
| 元组 `tuple` | `(31.8, 117.2)`      | 有顺序、创建后不可修改   | 坐标、固定配置     |
| 字典 `dict`  | `{"name": "小科"}`   | 通过唯一的键查找值       | 学生信息、一条订单 |
| 集合 `set`   | `{"Python", "实验"}` | 元素不重复、没有固定顺序 | 去重、成员判断     |

#### 列表

列表保存一组有顺序的数据，可以通过下标读取和修改：

```python
scores = [88, 72, 95, 60]
scores.append(81)
scores[1] = 75
scores.remove(60)
print(scores[0])
print(scores[1:3])
print(len(scores), sum(scores))
```

常用操作包括 `append`、`insert`、`remove` 和 `pop`。表达式 `value in values` 可以判断元素是否存在，`values[start:stop:step]` 按左闭右开规则切片。

#### 字典

字典用“键”查找对应的“值”：

```python
student = {"name": "小科", "score": 88, "submitted": True}
print(student["name"])
student["score"] = 91
student["group"] = 3
print(student)
```

`student["name"]` 要求键一定存在；`student.get("email", "未填写")` 可以在键不存在时返回默认值。使用 `items()` 可以同时遍历键和值：

```python
inventory = {"美式": 5, "拿铁": 3}

for drink, quantity in inventory.items():
    print(drink, quantity)
```

#### 元组与集合

元组适合保存不应随意修改的数据。集合会自动去重，并且适合快速判断某个元素是否存在：

```python
location = (31.8, 117.2)
tags = {"Python", "实验", "Python"}

print(location[0])
print(tags)  # 重复的 Python 只保留一次
print("实验" in tags)
```

综合实验中的 `orders` 是“列表中存放多个字典”：列表保持订单顺序，每个字典描述一条订单。这是实际数据处理中很常见的组合方式。

### 7.5 条件判断

Python 使用缩进表示代码层级。建议每层使用 4 个空格，不要混用 Tab 和空格。

```python
score = 85

if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "通过"
else:
    level = "未通过"

print(level)
```

逻辑运算符是 `and`、`or` 和 `not`：

```python
attendance = 0.9
if score >= 60 and attendance >= 0.8:
    print("满足课程通过条件")
```

随堂练习 3：给定温度，低于 10 输出“冷”，10 到 27 输出“舒适”，高于 27 输出“热”。

### 7.6 for 与 while 循环

`for` 适合逐个处理一组数据：

```python
scores = [88, 72, 95, 49]
passed = 0

for score in scores:
    if score >= 60:
        passed += 1

print(f"及格人数：{passed}")
```

`range(5)` 依次产生 0、1、2、3、4：

```python
for i in range(5):
    print(i)
```

`while` 在条件为真时反复执行，必须保证条件最终会变为假：

```python
countdown = 3
while countdown > 0:
    print(countdown)
    countdown -= 1
print("开始")
```

## 8. 读懂报错

报错时先看最后一行，再向上找文件名与行号。

- `SyntaxError`：语法不完整，常见原因是漏掉冒号、括号或引号。
- `IndentationError`：缩进层级不一致。
- `NameError`：变量还没有定义，或名称拼写不一致。
- `TypeError`：对不兼容的类型执行操作，例如字符串加整数。
- `IndexError`：列表下标超出范围。
- `KeyError`：字典中没有这个键。

排错顺序：确认 kernel → 从头运行 → 看最后一行错误 → 定位行号 → 检查变量值和类型。

## 9. 综合实验：校园咖啡店订单结算与营业分析

### 任务背景

咖啡店记录了一组订单。请使用变量、列表、字典和控制流完成结算与营业分析。不得使用 pandas、numpy，也不要求定义函数或类。

每条订单包含订单号、品类、饮品、单价、数量和会员状态。结算规则如下：

1. 数量小于等于 0 或单价小于等于 0 的订单无效，打印原因后用 `continue` 跳过。
2. 有效订单中，会员且购买不少于 3 杯时按八五折结算。
3. 只有会员条件成立时按九折结算；只有不少于 3 杯时按九五折结算。
4. 其他订单按原价结算。折扣条件按上述优先级判断，不能重复打折。

### 必做任务

1. 用 `for` 遍历订单，用 `continue` 跳过无效订单，并统计无效订单数。
2. 用嵌套或连续的 `if/elif/else` 按规则确定折扣，逐条打印原价、折扣和实付金额。
3. 统计有效订单数、总杯数、总营业额和会员订单数。
4. 使用字典 `category_cups` 分品类累计杯数。
5. 在循环中找出实付金额最高的订单号。
6. 循环结束后再用 `if/elif/else` 判断营业状态：营业额不少于 140 元且有效订单不少于 5 单为“繁忙”；否则营业额不少于 100 元为“正常”；其余为“清闲”。
7. 在 Markdown 单元回答实验问题，并运行全部单元。

### 本地自测与平台判题

学生版 notebook 提供公开的 `assert` 单元，只用于课堂练习和本地排错。没有红色报错并显示“✅ 全部自测通过”，说明当前示例数据下的以下检查全部通过：

- 有效订单数应为 `5`，无效订单数应为 `1`。
- 总杯数应为 `12`。
- 会员订单数应为 `3`。
- 分类杯数应为 `{'咖啡': 9, '茶饮': 3}`。
- 总营业额应为 `145.9` 元。
- 最高实付订单应为 `A005`。
- 营业状态应为“繁忙”。

正式成绩以平台自动判题为准。平台使用标准输入和标准输出，并设置 5 组测试数据：公开样例、全部原价、三种折扣、全部无效、边界与并列最大值。后 4 组建议设为隐藏数据。

## 11. 常见问题速查

### `conda` 找不到

Windows 请使用 Anaconda Prompt；macOS 请重开终端，必要时执行 `conda init zsh`。

### VS Code 运行的是另一个 Python

重新执行 **Python: Select Interpreter**，选择 `ai-lab`。在终端运行：

```bash
python -c "import sys; print(sys.executable)"
```

### notebook 没有 `ai-lab` kernel

先在终端执行：

```bash
conda activate ai-lab
conda install -c conda-forge ipykernel
```

然后重启 VS Code，再选择 kernel。

### 下载包很慢或失败

先记录完整报错，不要反复中断安装。可以按照 3.3 节切换到中科大镜像，并用 `conda config --show-sources` 检查实际生效的配置。课堂中可先使用同桌电脑完成 notebook；课后在稳定网络下重试。不要随意复制来路不明的镜像配置。
