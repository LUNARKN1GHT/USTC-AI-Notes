# 实验一平台自动判题配置

## 判题设置

- 判分依据：根据通过的测试用例数目给分
- 测试数据：5 组，每组 20 分
- 输出结果验证：完全匹配
- 性能判分：关闭
- AI 判分：关闭
- 建议将第 1 组设为公开样例，第 2～5 组设为隐藏数据

学生程序不得输出输入提示、订单明细、调试信息或其他文字。

## 题目规则

每条订单包含“订单号、品类、单价、数量、是否会员”。品类只使用 `coffee` 和 `tea`，会员使用 `1` 表示，非会员使用 `0` 表示。

1. 数量或单价小于等于 0 的订单无效，使用 `continue` 跳过。
2. 会员且购买不少于 3 杯时按八五折结算。
3. 仅满足会员条件时按九折结算。
4. 仅购买不少于 3 杯时按九五折结算。
5. 其他订单按原价结算，折扣不叠加。
6. 实付金额并列时保留先出现的订单；没有有效订单时输出 `NONE`。
7. 总营业额不少于 140 且有效订单不少于 5 单时为 `busy`；否则总营业额不少于 100 时为 `normal`；其余为 `quiet`。

固定输出六行：

```text
有效订单数 无效订单数
总杯数 会员订单数
咖啡杯数 茶饮杯数
总营业额（保留一位小数）
最高实付订单号
营业状态
```

## 测试数据 1：公开样例

命令行输入：

```text
6
A001 coffee 12.0 2 1
A002 coffee 18.0 1 0
A003 tea 10.0 3 1
A004 coffee 20.0 2 0
A005 coffee 12.0 4 1
A006 tea 9.0 0 0
```

标准输出：

```text
5 1
12 3
9 3
145.9
A005
busy
```
