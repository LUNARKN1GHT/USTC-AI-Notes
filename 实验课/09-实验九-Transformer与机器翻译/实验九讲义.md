# 实验九 · Transformer 与机器翻译

用一个小型 Transformer 把英文短句翻译成中文。实验八用图掩码规定一个节点可以读取哪些邻居。这次把同样的问题放到译文上，检查解码器预测下一个词元时可以读取哪些位置，再训练模型并分析实际译文。

## 开始实验

1. 在实验九目录中打开 [实验九_学生版.ipynb](实验九_学生版.ipynb)，选择包含 PyTorch 的 Python 内核。需要补装依赖时，在对应环境运行 `python -m pip install -r requirements.txt`。[依赖清单](requirements.txt)
2. 将 Notebook、[英中短句.tsv](英中短句.tsv) 和 [参考权重.pt](参考权重.pt) 放在同一目录。语料和权重随实验提供，安装依赖后可离线完成实验。
3. 按 Q1 到 Q7 分阶段运行。每题先写下预测，再补全本题的 TODO，运行对应检查后进入下一题。后面的批次构造、训练和解码会调用前面写的函数。

## 实验任务

学生版共有七处函数 TODO。每题的代码和验证结果都留在 Notebook 里。

| 题目 | 要写的函数 | 留下的证据 |
| --- | --- | --- |
| Q1 词元、ID 与词嵌入 | `ids_for` 按原顺序查词表，将未收录的词元映射到 `<unk>` | 重复词和未收录词的查表结果，以及位置和上下文改变前后的向量比较 |
| Q2 译文轨迹与训练目标 | `make_target_batch` 在右侧填充目标序列，构造错开一位的解码器输入和监督标签 | 一段生成轨迹、两条不同长度的目标序列填充和错位后的结果 |
| Q3 缩放点积注意力 | `scaled_dot_product_attention` 计算注意力权重和加权输出 | 一行手算和代码核对，以及改变值向量前后的权重与输出 |
| Q4 防止未来词元泄漏 | `make_causal_mask` 构造屏蔽未来位置的布尔掩码 | 同权重的有掩码与无掩码对照，以及自己设计的一次额外检查 |
| Q5 训练并诊断 | `token_loss` 对非 `<pad>` 标签的交叉熵求和，`update_parameters` 清空梯度、按有效词元数归一化后反传、裁剪梯度并更新参数 | 损失和更新检查、小批次更新前后的损失，以及逐轮训练和验证损失 |
| Q6 生成与比较 | `greedy_decode` 逐步选出下一个词元，在 `<eos>` 或长度上限处停止 | 生成轨迹、同权重的两种译文、自拟的一组最小对照句及数据检查 |
| Q7 循环模型对照（必做） | 运行现成的普通 RNN、GRU 和 LSTM | 参数量、验证损失、同一组短句的译文和信息传递路径 |

可以用 AI 辅助写代码和排错。请记录一条 AI 建议或自己的排错假设、你设计的检查、观察到的输出，以及输出支持的结论。

## 语料与备课材料

语料从 ManyThings 汇编的 Tatoeba 英中句对 `cmn-eng.zip`（2026-02-13 版）选取。按实验分词规则保留英文至多 10 个词元、中文至多 18 个词元的句对，按英文原句归组、去重和划分，得到 21,850 对训练数据和 1,150 对验证数据。课堂示例与指定的翻译检查句另行留出。中文原文保留简繁写法，每行保留原句和对应署名。这份语料依原数据的 CC BY 2.0 France 许可提供。[ManyThings 下载页](https://www.manythings.org/anki/) · [Tatoeba](https://tatoeba.org/) · [CC BY 2.0 France](https://creativecommons.org/licenses/by/2.0/fr/)
