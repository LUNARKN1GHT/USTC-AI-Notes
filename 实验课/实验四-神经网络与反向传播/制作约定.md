# 实验四材料统一约定

本文件记录本版材料的教学与接口选择，供教师调整课时及维护材料使用；原设计大纲保留不改。总课时未定，不规定分钟数。基础任务与去激活对照必做，学习率对照为进阶任务（教师可改为必做），PyTorch 为可跳过的教师演示。

## 数学与训练设置

- Q1：形状与计算图；Q2：前向传播；Q3：损失；Q4：反向传播；Q5：梯度检查；Q6：单次更新；Q7：封装与完整训练；Q8：去掉激活对照；Q9：学习率对照；Q10：PyTorch 演示（选做）。
- 样本按行：X、y 为 (N,1)，W1 (1,H)，b1 (1,H)，W2 (H,1)，b2 (1,1)。Z1=X@W1+b1，A1=tanh(Z1)，y_pred=A1@W2+b2，输出层不激活。
- L=mean((y_pred-y)**2)，单输出时 dY=2*(y_pred-y)/N；不含 1/2。偏置梯度保留二维形状。
- 数据 X=linspace(-pi,pi,64).reshape(-1,1)，y=sin(X)，无噪声。绘图网格 400 点，同一区间。网格误差是区间内拟合检查，不宣称外推或真实测试泛化。
- H=16，seed=42；default_rng(seed) 依次生成 W1~N(0,1)、W2~N(0,1/sqrt(H))；偏置全零。float64。
- 基础 lr=0.02、epochs=10000，全批量下降。损失 history 长度通常 epochs+1，索引为已完成更新次数，包含初始损失与最终参数损失。
- Q8 同种子、同数据、同宽度、同学习率、同步数，仅 activation 从 tanh 改为 linear。Q9 学习率为 0.002、0.02、0.2，每次重建相同初始模型；非有限值或浮点溢出时停止并报告，回滚到上一次有限参数；history 仅包含成功且有限的更新，completed_updates 与 attempted_update 分别报告，勿把截断曲线误读为收敛。
- 试跑参考：基础最终训练 MSE 约 0.00328；linear 约 0.20718；小学习率约 0.02364；大学习率可能溢出。数字是诊断参考，不是唯一评分阈值。

## 文件与固定接口

- nn_numpy.py：学生模块（核心 TODO）；nn_numpy_参考答案.py：教师可运行模块。均定义 mse_loss(y_pred,y)、TwoLayerNet(hidden_dim=16,seed=42,activation='tanh')。
- net.params 为字典，键依次 W1,b1,W2,b2。forward(X) 返回 (y_pred,cache)，cache 含 X,Z1,A1；backward(y_pred,y,cache) 返回同键梯度字典，不能更新参数；step(grads,lr) 原地更新参数，返回 None。linear 模式隐藏导数为 1。
- lab_utils.py：教师提供 make_sine_data(n_samples=64,noise_std=0.0,seed=42) -> (X,y)；gradient_check(net,X,y,epsilon=1e-5,atol=1e-7,rtol=1e-4) -> 字典，每参数含 max_abs_error、max_rel_error、passed。逐元素中心差分，扰动后恢复参数，按 abs_error<=atol+rtol*(abs(analytic)+abs(numeric)) 判定。不可偷用参考模块，工具适用于学生模型。
- lab_utils.py 提供 plot_results(X,y,grid,y_grid_pred,history,title='') -> (fig,axes)，返回损失及拟合双图。训练循环必须留在 notebook。
- 学生和参考 notebook 均先 Q2–Q6 用独立函数逐步实现，再 Q7 整理至类。独立函数固定为 forward_pass(X,params,activation='tanh')、backward_pass(y_pred,y,cache,params,activation='tanh')、update_params(params,grads,lr)，与类对应接口语义一致。独立损失函数名 loss_mse，避免与导入冲突。
- 学生 notebook 使用 nn_numpy；参考 notebook 使用 nn_numpy_参考答案，完全可从头执行，展示答案和解释。学生 TODO 明确抛出 NotImplementedError，未作答时不伪装为可执行成品。训练循环保留学生补全位置，参考版完整实现；数据/绘图/有限差分工具已提供。
- 梯度检查小网络 H=3，seed=7，X=[[-0.7],[0.2],[0.9]]，y=sin(X)，同时覆盖 tanh 和 linear。Q5 可用包装器把分步函数适配给工具，Q7 再检查封装后的模型。
- 验证参考答案.py：可独立执行的数学与接口验证，覆盖形状、有限差分、偏置求和、参数恢复、不原地改梯度/反向不更新参数、单次小步下降、训练与对照。
- 实验四讲义.md 与 notebook 的 Q1–Q10 编号、必做范围、提交要求完全一致。提交学生 notebook、nn_numpy.py 和一条真实排错记录（可写在 notebook）；保留运行输出，重新启动后全量执行。
