# 实验四设计大纲：用 NumPy 实现神经网络与反向传播

## 一、实验定位

本次实验是编程基础训练与课程主体内容的首次正式衔接。学生已学习 Python 函数、类、模块化及 NumPy 基础，理论课近期重点为简单神经网络与反向传播（BP）算法。

实验以 NumPy 实现固定结构的单隐藏层神经网络为主，将理论课中的前向传播、链式法则和梯度下降转化为可运行、可检查的程序。PyTorch 作为结尾过渡，不作为本次必做任务的前置知识。

实验主线：

> 前向传播 → 损失计算 → 反向传播 → 梯度检查 → 参数更新 → 完整训练 → 对照实验

## 二、学习目标

1. 将网络结构、数学符号与 NumPy 数组及其形状对应起来。
2. 完成单隐藏层网络的前向传播与损失计算。
3. 将链式法则转化为各层参数的梯度计算。
4. 区分反向传播求梯度与梯度下降更新参数。
5. 使用有限差分检查手写梯度的正确性。
6. 结合损失曲线和预测曲线解释训练过程。
7. 通过受控对照实验分析非线性激活和学习率的作用。
8. 理解自动求导与本次手写 BP 的对应关系。

## 三、教学内容与边界

### 3.1 本次重点

- 批量输入、参数和中间结果的形状；
- 固定两层全连接网络的前向传播；
- 均方误差损失；
- 基于链式法则的矩阵形式反向传播；
- 权重梯度与偏置梯度；
- 有限差分梯度检查；
- 梯度下降与完整训练循环；
- 实验结果的可视化、验证和解释。

### 3.2 本次不展开

- 任意层数网络和通用神经网络框架；
- 复杂类继承和工程封装；
- 多分类、softmax 与交叉熵的综合实现；
- 小批量数据加载、GPU 训练和复杂优化器；
- PyTorch API 的系统教学；
- 大规模调参和完整的模型选择流程。

## 四、主实验任务

### 4.1 主题

**使用单隐藏层神经网络拟合一维正弦函数。**

### 4.2 数据与模型范围

- 以无噪声样本完成基础流程，带噪声样本作为拓展；
- 使用单输入、单输出、单隐藏层网络；
- 隐藏层采用非线性激活，输出层采用线性输出；
- 激活函数和数学符号尽量与理论课保持一致；
- 使用均方误差和全批量梯度下降；
- 使用固定随机种子，记录关键实验设置。

### 4.3 核心产出

- 可运行的 NumPy 网络；
- 手写梯度与有限差分的检查结果；
- 损失曲线与函数拟合曲线；
- 对照实验记录与简短解释。

## 五、分阶段教学安排

| 阶段 | 主要任务 | 完成标志 |
| --- | --- | --- |
| 理论回顾与任务导入 | 对齐网络结构、计算图和拟合任务 | 能说明输入、输出、参数和训练目标 |
| 前向传播 | 完成各层计算并检查形状 | 得到形状正确的预测结果 |
| 损失计算 | 将预测误差转换为标量目标 | 能说明损失的计算与平均约定 |
| 反向传播 | 逐层计算并汇总参数梯度 | 各梯度形状与对应参数一致 |
| 梯度检查 | 对比手写梯度与有限差分 | 检查通过，能解释不一致时的排查方向 |
| 单次参数更新 | 完成一次梯度下降并比较更新前后结果 | 能区分求梯度与更新参数 |
| 完整训练 | 重复训练步骤并记录结果 | 得到损失曲线和拟合曲线 |
| 对照实验 | 改变单一因素并分析现象 | 有事前预测、结果证据和事后解释 |
| PyTorch 过渡 | 演示自动求导与手写 BP 的对应关系 | 理解框架代替了哪部分工作 |

教师讲解与学生操作交替进行。先完成一次可检查的计算与更新，再进入完整训练。

## 六、代码组织与任务分工

### 6.1 组织方式

- 先在 notebook 中分步实现和验证；
- 再将核心计算整理到固定结构的网络类中；
- 类的职责限定为参数初始化、前向传播、反向传播和参数更新；
- 训练循环与绘图保留在 notebook 中，便于观察过程。

### 6.2 教师提供

- 数据生成和可视化工具；
- 网络类及训练循环骨架；
- 与理论课一致的符号、形状和损失约定；
- 有限差分检查工具及必要自测；
- 实验记录与对照分析模板。

### 6.3 学生完成

- 前向传播与必要中间结果的保存；
- 损失计算；
- 各参数的梯度计算；
- 参数更新；
- 梯度检查、训练验证及结果解释。

## 七、验证与排错主线

1. 检查输入、参数、中间量和梯度的形状。
2. 统一样本排列、损失平均和偏置求和约定。
3. 在极小网络、少量样本上进行有限差分检查。
4. 检查单次更新的方向、步长和数值变化。
5. 结合损失曲线与预测曲线判断完整训练表现。
6. 重启 notebook kernel 并从头运行，确认结果可复现。

强调：损失下降不是梯度实现正确的充分证据；单次更新也不保证在任意学习率下使损失下降。

## 八、对照实验与拓展

### 8.1 核心对照

- 去掉隐藏层激活函数，比较表达能力与拟合结果；
- 改变学习率，比较训练速度与稳定性。

每次只改变一个因素，先提出预测，再运行实验，最后结合数学关系解释结果。根据课时确定一项必做或两项均为必做。

### 8.2 选做拓展

- 改变隐藏层宽度；
- 加入观测噪声；
- 比较训练区间内外的预测；
- 将网络迁移到 XOR 或双月牙分类任务，另行说明输出与损失的调整。

## 九、PyTorch 过渡环节

- 简要认识 Tensor、需要求梯度的参数和自动求导；
- 使用相同输入、参数和损失，对比 NumPy 手写梯度与 PyTorch 自动求导结果；
- 明确自动求导与参数更新的分工；
- 为下一次系统学习 PyTorch、网络模块和优化器建立联系。

该环节以教师演示为主。课时不足时整体移至下一次实验，不压缩 BP 实现与梯度检查。

- 预留矩阵形状、梯度公式和训练异常的排错时间；
