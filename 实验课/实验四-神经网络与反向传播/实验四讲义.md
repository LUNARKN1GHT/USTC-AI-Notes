## 2. 实验约定

本实验用无噪声样本拟合正弦函数，样本按行排列。这里的 `linspace(a, b, n)` 指的是在区间 $[a,b]$ 上均匀抽取 $n$ 个点：

$$
X=\operatorname{linspace}(-\pi,\pi,64),\qquad y=\sin(X).
$$

代码将二者整理为 `(64, 1)`，统一使用 `float64`。网络只有一个隐藏层：

$$
Z_1=XW_1+b_1,\qquad A_1=\tanh(Z_1),\qquad \hat y=A_1W_2+b_2.
$$

输出层采用线性输出。损失为

$$
L=\frac1N\sum_{i=1}^N(\hat y_i-y_i)^2,
$$

即 `mean((y_pred - y) ** 2)`，**不含额外的 $1/2$**。

| 设置       | 基础实验取值                                                                          |
| ---------- | ------------------------------------------------------------------------------------- |
| 隐藏层宽度 | `H=16`                                                                                |
| 随机种子   | `seed=42`                                                                             |
| 初始化     | 同一 `default_rng(seed)` 依次生成 `W1`、`W2`；标准差分别为 `1`、`1/sqrt(H)`；偏置为零 |
| 学习率     | `lr=0.02`                                                                             |
| 更新次数   | `epochs=10000`                                                                        |
| 梯度下降   | 每次使用全部 64 个样本                                                                |
| 绘图网格   | 同一训练区间内均匀取 400 点                                                           |

初始化顺序也会影响随机结果。不要在对照中随意换种子、交换抽样顺序或复用已训练参数。网格上的误差用于检查区间内拟合情况，不能据此宣称模型具有区间外预测能力或真实测试泛化能力。

## 3. 分阶段题目

### Q1：形状与计算图（必做）

在 notebook 中填写形状表，并说明每一行代表什么。一般样本数记作 `N`，隐藏层宽度记作 `H`。

| 变量       | 含义               | 形状               |
| ---------- | ------------------ | ------------------ |
| `X`、`y`   | 输入与目标         | `(N, 1)`           |
| `W1`、`b1` | 隐藏层权重与偏置   | `(1, H)`、`(1, H)` |
| `Z1`、`A1` | 隐藏层激活前后结果 | `(N, H)`、`(N, H)` |
| `W2`、`b2` | 输出层权重与偏置   | `(H, 1)`、`(1, 1)` |
| `y_pred`   | 预测               | `(N, 1)`           |
| `L`        | 整批样本的损失     | 标量               |

计算图为 `X → Z1 → A1 → y_pred → L`。参数在各自的仿射变换处进入计算；反向传播从损失沿计算图倒序计算导数。

解释以下问题：为什么 `X @ W1` 的结果是 `(N, H)`？为什么所有样本共用一行偏置？`@` 与 `*` 分别对应什么数学运算？当 `y` 误写成 `(N,)` 时，为什么减法可能不报错却产生错误的 `(N, N)` 结果？

### Q2：前向传播（必做）

先在 notebook 中实现：

```python
forward_pass(X, params, activation="tanh")
```

返回 `(y_pred, cache)`，其中 `cache` 至少保存 `X`、`Z1`、`A1`。`params` 的键固定为 `W1`、`b1`、`W2`、`b2`。当 `activation="linear"` 时，令 `A1=Z1`，为 Q8 的对照做好准备。

完成后检查各中间量与输出的形状、数值是否有限。解释缓存的作用：反向传播需要本次前向得到的中间结果。缓存不能来自另一批输入或另一组参数。

### Q3：损失计算（必做）

实现独立函数 `loss_mse(y_pred, y)`，返回标量 MSE。使用小数组手算一个例子，再与程序比较。讨论预测等于目标时损失为何为零，以及样本量翻倍、把原样本重复一遍时，平均损失是否变化。

损失的“平均约定”必须贯穿后续推导。对本实验的单输出网络：

$$
G_Y=\frac{\partial L}{\partial\hat y}=\frac{2}{N}(\hat y-y).
$$

这里的 `N` 是样本数。若日后扩展为多输出且仍对全部元素取平均，分母也必须相应调整；本次不扩展该接口。

### Q4：反向传播（必做）

实现：

```python
backward_pass(y_pred, y, cache, params, activation="tanh")
```

返回与 `params` 同键的梯度字典。反向传播只求梯度，不能更新参数。按照“当前梯度 × 当前运算的局部导数”依次推导：

$$
\begin{aligned}
\nabla_{W_2}L &= A_1^\mathsf{T}G_Y, &
\nabla_{b_2}L &= \sum_{i=1}^N (G_Y)_{i,:},\\
G_{A_1} &= G_YW_2^\mathsf{T}, &
G_{Z_1} &= G_{A_1}\odot(1-A_1^2),\\
\nabla_{W_1}L &= X^\mathsf{T}G_{Z_1}, &
\nabla_{b_1}L &= \sum_{i=1}^N (G_{Z_1})_{i,:}.
\end{aligned}
$$

`linear` 模式的局部导数为 1，因此 `G_Z1=G_A1`。`tanh` 模式使用 $\tanh'(z)=1-\tanh^2(z)$；这里平方的是缓存的 `A1`，不要误写成 `1-Z1**2`。

**为什么偏置梯度是求和？** 前向时，同一个偏置被广播到每个样本。每条样本路径都会对同一个偏置产生贡献，所以反向时沿样本轴汇总。用 `sum(axis=0, keepdims=True)` 保留二维形状。损失中的 `1/N` 已在 `G_Y` 内，不能再对偏置梯度取一次平均。

逐个检查梯度形状是否等于对应参数形状，解释矩阵转置的作用。形状正确仅是必要条件，下一题要用独立方法检查数值。

### Q5：有限差分梯度检查（必做）

暂时不训练。使用 `H=3`、`seed=7` 的小网络，输入为 `[[-0.7], [0.2], [0.9]]`，目标为 `sin(X)`。分别检查 `tanh` 与 `linear` 模式。notebook 提供包装方式，将 Q2–Q4 的函数适配给教师工具：

```python
gradient_check(net, X, y, epsilon=1e-5, atol=1e-7, rtol=1e-4)
```

工具逐个扰动参数元素，用中心差分近似导数：

$$
g_{\mathrm{num}}=\frac{L(\theta+\epsilon)-L(\theta-\epsilon)}{2\epsilon}.
$$

每次只改变一个参数元素，其他参数与输入保持固定，计算后恢复原值。它不依赖手写 BP 公式，因此可以作为独立检查。检查过程中不能执行参数更新。

工具返回每组参数的 `max_abs_error`、`max_rel_error` 和 `passed`。实际通过条件逐元素判断：

$$
|g_{\mathrm{ana}}-g_{\mathrm{num}}|
\leq \mathrm{atol}+\mathrm{rtol}(|g_{\mathrm{ana}}|+|g_{\mathrm{num}}|).
$$

绝对容差照顾接近零的梯度，相对容差考虑梯度的量级。最大相对误差只是诊断信息；接近零时它可能显得很大，应结合绝对误差和 `passed` 判断。`epsilon` 过大会引入近似误差，过小会放大浮点相消误差，并非越小越好。

保留两种激活下四组参数的完整检查结果。若失败，依次检查损失平均系数、`tanh` 导数、转置、偏置求和及缓存。不要靠放宽容差把错误隐藏起来。检查通过支持当前实现，但有限输入上的检查也不是对所有情况的数学证明。

### Q6：单次参数更新（必做）

实现 `update_params(params, grads, lr)`，按下式原地更新参数并返回 `None`：

$$
\theta\leftarrow\theta-\eta\nabla_\theta L.
$$

先保存参数副本和更新前损失，完成前向、求梯度、更新、重新前向，再比较损失。使用 notebook 给定的小步长进行验证，并确认梯度字典没有被更新函数修改。

解释：BP 决定“梯度是什么”，梯度下降决定“怎样用梯度修改参数”。求得所有梯度后才能更新，不能先更新 `W2` 再用它计算旧前向的隐藏层梯度。

足够小的步长通常使非驻点处的损失下降，但任意学习率下的一次更新不保证下降。反过来，损失下降也不足以证明梯度完全正确；应先通过 Q5，再判断步长。

### Q8：去掉隐藏层激活的对照（必做）

运行前先写预测。重新创建相同初始化的两个模型，保持数据、宽度、随机种子、学习率和更新次数一致，仅改变 `activation`：`tanh` 与 `linear`。不要在训练好的模型上直接切换激活后继续训练。

去掉激活后：

$$
\hat y=(XW_1+b_1)W_2+b_2
=X(W_1W_2)+(b_1W_2+b_2).
$$

因此两个仿射层合起来仍是一个仿射函数。讨论为什么增加隐藏层宽度也不能使该 `linear` 模型表示完整的正弦曲线。这个结论来自表达式；某一次训练曲线本身不能证明找到了全局最优。

保存两组损失曲线、拟合曲线和误差。参考设置下 `linear` 最终训练 MSE 约为 `0.20718`。按以下格式记录，不以“一个好、一个差”结束：

| 改变的因素               | 保持不变的设置               | 事前预测   | 结果证据   | 数学解释         |
| ------------------------ | ---------------------------- | ---------- | ---------- | ---------------- |
| 隐藏激活 `tanh / linear` | 数据、初值、宽度、步长、步数 | 运行前填写 | 损失与图像 | 联系等效仿射函数 |

## 4. 常见错误与定位顺序

| 现象                       | 优先检查的依据                                               |
| -------------------------- | ------------------------------------------------------------ |
| 矩阵乘法报错               | 写出左右操作数的形状，核对内侧维度；不要盲目添加转置         |
| 不报错但损失异常           | `y_pred`、`y` 是否都是 `(N, 1)`，减法是否错误广播            |
| 只有偏置梯度不通过         | 是否沿样本轴求和、保留维度，是否重复除以 `N`                 |
| 所有梯度相差固定倍数       | MSE 是否含 `1/2`，是否漏掉或重复平均                         |
| 隐藏层梯度失败             | `tanh` 导数、`W2` 转置、缓存对应关系，以及是否提前更新了参数 |
| 检查后参数变了             | 有限差分是否完整恢复扰动，检查期间是否意外调用更新           |
| 梯度检查通过但训练发散     | 学习率、更新符号、更新次数与有限性；先缩小步长做一次更新     |
| 修改模块后表现不变         | 文件是否保存，kernel 是否重新导入了最新版本                  |
| 图上“最终损失”与预测不对应 | 是否记录了更新前的损失，却绘制更新后的参数                   |
| 对照不能复现               | 是否复用了已训练参数，数据、种子和随机数抽取顺序是否一致     |
