## 实验中的 AI 辅助

可以用 AI 查 API、解释报错、提出测试样例或讨论对照实验。先写下自己的预期，再请 AI 帮你缩小问题范围。用一个可手算的输入、一次梯度检查或一组固定数据划分的对照结果验证建议。记录关键假设、实际观察和由此作出的修改，确保能解释自己的实现与结论。
