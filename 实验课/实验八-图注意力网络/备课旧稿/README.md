# 实验七：图注意力网络与 Cora 论文分类

利用少量论文标签，在完整引用网络上预测论文研究方向。主线为“数据与图 → 小图注意力 → GAT → 三组对照 → 注意力分析 → 最终测试”，按 120 分钟组织。

## 文件与使用

| 文件 | 用途 |
| --- | --- |
| `实验七_学生版.ipynb` | 学生入口；补全 Q1、Q2、Q3a、Q3b，完成运行与解释 |
| `实验七_参考答案.ipynb` | 完整实现、解释、实际运行输出与教师讨论示例 |
| `lab_utils.py` | 教师提供的数据读取、划分、按边分组运算、训练、指标与绘图工具 |
| `cora/` | 已提供的原始本地数据，无需下载 |
| `实验七设计大纲.md` | 任务定位、数学约定、课堂安排与评价要求 |
| `参考运行记录.json` | 种子 42 的配置、环境、逐轮曲线、最佳轮次、参数量、耗时与测试指标 |
| `重复运行记录.json` | 三个预先规定的种子及汇总；固定同一数据划分 |
| `验证参考答案.py` | 独立核验核心数学、接口与标签使用；可完整执行参考 notebook |
| `制作notebook.py` | 维护入口；同时生成两版 notebook，避免任务与参考实现脱节 |

学生材料至少保留学生 notebook、`lab_utils.py` 和完整 `cora/` 文件夹；首次使用时附上本说明和依赖文件。教师参考答案与制作脚本可单独保留。

沿用已有 `ai-lab` 环境即可。依赖见 `requirements.txt`，无需安装 PyG、DGL、labml 或 scikit-learn。在实验七目录启动 Jupyter 并打开学生版，补全 TODO 后顺序执行。未作答时主动抛出 `NotImplementedError`；Q6 的 `FROZEN` 需在完成验证分析后手动改为 `True`。

默认 CPU、最多 4 个线程。CUDA 可通过 `LAB7_DEVICE` 指定，但本次仅验证 CPU；MPS 不列入本版运行范围。环境变量 `LAB7_EPOCHS` 可用于开发阶段缩短运行，默认 300，任何改动均记录到输出中。使用不同预算的结果不与正式参考结果混为一组比较。

运行后生成 `输出/`：

- `split_seed42.json`：训练、验证、测试的节点下标与论文 ID、固定类别顺序、原始文件 SHA-256；
- `运行记录.json`：本次配置、环境、曲线和最终测试指标；
- `验证集选定模型.pt`：按验证集选定的模型权重及重建信息，不含优化器状态。

`输出/` 已在本目录忽略规则中排除。提交作业时另附运行记录和划分；无需提交开发缓存。

## 三组比较与数据隔离

| 组别 | 关系与权重 | 有效可训练参数 |
| --- | --- | ---: |
| A | 仅自环，保留多头特征变换 | 92,160 |
| B | 引用边与自环，邻域内固定等权 | 92,160 |
| C | 与 B 相同，学习 GAT 权重 | 92,302 |

三组都存储 92,302 个参数；A、B 的 142 个打分参数被冻结且不参与计算。B 是自拟的等权对照，不称为标准 GCN。三组共享特征变换的初值，独立训练，不共享已训练权重。

主划分为每类 20 个训练节点，共 140；分层验证 500；测试 2,068。所有节点特征与关系可参与前向，训练损失仅使用训练标签。训练函数的接口只接收训练与验证标签；注意力分析仅展示这两部分的类别，测试邻居标为“?”。配置与模型冻结后，Q6 才统一计算预先规定的三组测试指标。

局部检查在固定模型上移除某条无向边的两个方向，保留自环、重算注意力；它与删边后重新训练用途不同。归一化检查及注意力图使用 dropout 前的权重。

## 本机实测参考

环境为 Python 3.12.14、PyTorch 2.14.1、NumPy 2.5.3、Matplotlib 3.11.2，arm64 CPU，4 线程。统一训练 300 轮，Adam，学习率 0.005、权重衰减 0.0005，特征与注意力 dropout 均为 0.6。训练环境核心信息与完整数值见 JSON 记录。

| 组别 | 最佳轮次（种子 42） | 验证准确率 | 测试准确率 | 测试 Macro-F1 | 训练与逐轮评估耗时 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 118 | 61.80% | 58.41% | 0.5759 | 3.4 秒 |
| B | 139 | 83.00% | 80.03% | 0.7848 | 4.0 秒 |
| C | 294 | 81.80% | 79.26% | 0.7787 | 5.9 秒 |

耗时覆盖训练、逐轮评估与最佳参数快照，不含数据读取、绘图、最终测试和 Jupyter 启动；普通学生电脑需另行测量，不能直接照搬。

固定划分，种子 42、2026、3407 的重复结果（均值 ± 样本标准差，`ddof=1`）：

| 组别 | 测试准确率 | 测试 Macro-F1 |
| --- | ---: | ---: |
| A | 58.75% ± 0.30% | 0.5766 ± 0.0020 |
| B | 79.56% ± 0.48% | 0.7813 ± 0.0038 |
| C | 79.37% ± 0.10% | 0.7815 ± 0.0028 |

这些结果支持当前配置下邻居聚合有用，未显示学习注意力相对等权聚合有稳定优势。它们适合引导学生解释“模型更复杂是否一定更好”，不设为准确率门槛，也不推断注意力普遍无效。三个初始化只描述固定划分上的训练随机性，不是跨划分或显著性检验。

## 维护与核验

在已安装依赖的环境中，从本目录运行：

```bash
python 验证参考答案.py
python 验证参考答案.py --execute
python 验证参考答案.py --repeat
python 制作notebook.py --refresh-notes
```

第一条检查数据、确定性划分、不对称图的稠密／按边前向与参数梯度、分组 softmax 有限差分、置换等变性、等权与自环、训练掩码、最佳模型恢复、参数初值、指标和学生占位。第二条用当前解释器启动本地 Jupyter 内核，从头执行参考版并保存输出；正式默认配置写出 `参考运行记录.json`。第三条在已有主记录基础上，运行另外两个固定种子并保存汇总；第四条将实测讨论更新到参考 notebook，保留原执行输出。

完整执行需要本地 Jupyter 内核可绑定回环端口。测试与 notebook 均只使用本地数据，没有上传步骤。

修改任务或代码后，运行 `python 制作notebook.py` 重新生成两版，再进行相应核验与完整执行；**重新生成会清空两版的执行输出**。如果只刷新教师讨论，使用 `--refresh-notes`。主训练配置变更后需重跑主记录与所有预定种子，更新本说明，避免混用旧记录。

本次已完成参考版从头运行及三种子重复，并检查训练曲线、局部注意力图、混淆矩阵的显示。学生版不保留答案输出，避免用参考结果代替学生自己的运行。
