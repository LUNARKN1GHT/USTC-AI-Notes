# 实验七设计大纲：图注意力网络与 Cora 论文分类

> 实施稿：承接实验五、六的训练与评价流程，以 GAT 半监督节点分类为主任务，通过“仅自身信息—邻居等权聚合—学习注意力”研究关系信息与聚合方式的作用。学生版、参考版及公共工具已制作，并完成 CPU 预跑与三个固定种子的重复实验，见本目录 README 和运行记录。

## 一、实验定位

实验六研究图像中的空间结构怎样帮助分类，本次研究样本之间的关系怎样帮助分类。

核心问题：

> 当只有少量论文有类别标签时，引用关系能否帮助预测其他论文的研究方向？学习邻居权重是否比等权聚合更有用？

实验主线：

> 认识图数据 → 核验一次邻居聚合 → 完成 GAT 分类 → 设计结构与权重对照 → 分析注意力与预测 → 用证据形成结论

允许学生使用 AI 查询接口、生成辅助代码与排错。课堂重点是定义问题、提出假设、控制比较条件和检查解释，不安排大段函数用法练习。

## 二、学习目标

1. 说明 Cora 中节点、边、节点特征和标签的含义，将原始文件转换为图学习输入。
2. 区分论文 ID 与张量下标，说明双向建图、自环和特征归一化的作用。
3. 理解传导式半监督学习，区分“看见节点特征与连接”和“使用节点标签训练”。
4. 用小图解释特征变换、邻居打分、邻域内 softmax 与加权聚合，理解多头拼接和平均。
5. 使用相同的数据划分完成三组对照，分别研究邻居信息与学习注意力的作用。
6. 结合总体指标、类别表现、局部邻域与注意力检查结果，区分观察事实、可能解释和进一步检验。

## 三、数据与任务定义

### 3.1 使用本地原始数据

直接使用 `cora/cora.content`、`cora/cora.cites` 和 `cora/README`，不依赖课上联网下载，也不替换为可能具有不同预处理或划分的库内置版本。

本地文件检查结果如下：

| 项目 | 数值或含义 |
| --- | --- |
| 节点 | 2,708 篇论文，ID 唯一 |
| 特征 | 每节点 1,433 维二值词特征，表示词是否出现 |
| 类别 | 7 类 |
| 原始引用记录 | 5,429 条，无自环，端点均存在于节点文件 |
| 无向化并去重后的边 | 5,278 条 |
| 连通情况 | 无孤立节点，78 个连通分量，最大分量 2,485 个节点 |
| 同类边比例 | 约 81.0%，按无向去重边计算 |

类别数量分别为：Case_Based 298、Genetic_Algorithms 418、Neural_Networks 818、Probabilistic_Methods 426、Reinforcement_Learning 217、Rule_Learning 180、Theory 351。

完整标签的统计仅作为教师对数据的描述，不作为模型输入或调参依据。数据不提供原始摘要和词表映射，不要求解释某一列对应的具体单词。

### 3.2 从文件到张量

- `cora.content` 每行依次为论文 ID、1,433 个特征、类别。保留文件行顺序，建立论文 ID 到连续下标的映射。
- 类别按固定排序映射为 0–6，保存类别顺序，不使用无序集合决定编码。
- `cora.cites` 每行为“被引用论文 ID、引用论文 ID”，原始方向为第二项指向第一项。
- 主实验采用无向关系：任一方向存在引用，就允许双方交换信息；去除重复关系，再为每个节点添加一次自环。
- 无向边转换为两个有向消息条目后有 10,556 条，加自环后共有 13,264 条消息条目。明确邻接矩阵的行表示接收节点、列表示发送节点。
- 节点特征按行除以该行特征和；对全零行保留零向量，避免除零。

模型输入为 `X: (2708,1433)` 与邻接关系，整数标签为 `y: (2708,)`，输出为七类 logits，形状 `(2708,7)`。主实验保留所有节点与连通分量。

### 3.3 任务与数据划分

任务是固定图上的七分类，即传导式半监督节点分类。

使用固定划分种子 42：每类抽取 20 个训练节点，共 140 个；从剩余节点中分层抽取共 500 个验证节点；剩余 2,068 个节点用于测试。教师提供确定性划分并保存索引，所有主比较复用相同划分。该方案是课堂自定义划分，不宣称复现公开基准。

训练时可以访问完整图和全部节点特征，但交叉熵仅在训练节点上计算：

\[
\mathcal L=-\frac{1}{|V_{\mathrm{train}}|}
\sum_{i\in V_{\mathrm{train}}}\log p_{i,y_i}.
\]

验证标签只用于评价与模型选择，测试标签只用于冻结方案后的最终评价。不能把真实类别作为节点特征，不能将验证或测试节点加入分类损失。

这项实验评价已知图中未知标签的预测，不据此声称模型可以泛化到未来新论文或另一张图。

## 四、模型与核心计算

### 4.1 两层 GAT

实施结构为：

```text
X: (2708,1433)
 → 特征 Dropout
 → 多头图注意力层：8 头，每头 8 维，拼接为 64 维
 → ELU
 → 特征 Dropout
 → 输出图注意力层：1 头，7 维
 → logits: (2708,7)
```

单头计算为：

\[
z_i=Wh_i,\qquad
e_{ij}=\operatorname{LeakyReLU}\!\left(a^\top[z_i\Vert z_j]\right),
\]

\[
\alpha_{ij}=\frac{\exp(e_{ij})}
{\sum_{k\in\mathcal N(i)\cup\{i\}}\exp(e_{ik})},
\qquad
h'_i=\sum_{j\in\mathcal N(i)\cup\{i\}}\alpha_{ij}z_j.
\]

掩码使非邻居不参与 softmax。第一层各头输出拼接，输出层直接产生 logits；不在交叉熵前添加 softmax。注意力系数的 dropout 在邻域 softmax 后实施。

### 4.2 实现范围与资源控制

主方案使用 PyTorch 按边计算消息与分组 softmax，教师提供分组运算辅助函数。学生在小图练习和 GAT 层骨架中完成注意力的核心逻辑，不要求从头实现稀疏算子。

避免对全部节点对构造高维特征拼接。小图可以使用稠密矩阵解释掩码，完整 Cora 训练使用按边实现。若备课时选择图学习库，应固定依赖版本，并保证学生仍能在小图上检查同一聚合过程。

注意力输出的约定为“某个接收节点，对其发送邻居的权重”。可视化与索引代码沿用同一方向，避免图画对了却解释反了。

## 五、三组主对照

| 组别 | 图关系 | 聚合权重 | 研究问题 |
| --- | --- | --- | --- |
| A：仅自身信息 | 仅自环 | 每节点只有自身，softmax 后权重为 1 | 仅凭论文自身特征能做到什么程度？ |
| B：邻居等权聚合 | 引用边与自环 | 对每个节点的邻居及自身固定等权 | 在当前配置下，加入邻居聚合有什么变化？ |
| C：学习注意力 | 与 B 相同 | 由 GAT 打分并在邻域内归一化 | 学习权重相对等权聚合有什么变化？ |

B 在 dropout 前使用 `1 / 邻域大小`，包含自身；不学习打分参数。它是课堂构造的固定等权聚合版本，不称为标准 GCN。A 也保留多头特征变换与激活，不直接等同于任意一个 MLP 基线。

三组使用同一套模型骨架，仅切换关系与权重模式。固定数据划分、特征处理、层数、头数、总隐藏维度、激活、dropout、优化器和训练预算。可共享的特征变换参数使用相同初值；C 额外学习打分参数。注意力 dropout 三组按相同规则实施，不要求不同计算路径具有完全相同的随机掩码。

A 与 B 比较加入邻居聚合后的效果；B 与 C 比较固定与可学习权重的效果。后者同时包含学习机制和额外可训练参数的差异，不把结果解释为排除了所有其他因素的因果证明。

先写预测，再运行。接受三组性能接近、GAT 未改善或不同种子排序变化等结果，要求检查实现并限定结论。

| Q1 数据与建图 | 完成 ID 映射、特征与标签提取、双向边及自环 | 图中的一条边允许谁向谁发送信息？ | 形状、节点与边数检查及解释 |

| Q4 三组对照 | 独立训练 A、B、C，保存各自最佳验证模型 | 邻居信息与学习权重分别带来什么？ | 训练／验证曲线及对照表 |
| Q5 局部分析 | 观察固定验证节点的邻域与注意力，进行边移除检查 | 注意力大是否就代表因果重要？ | 局部图、权重与预测变化及解释边界 |

### 6.1 小图必须能检查什么

教师给出一个带自环的小图，包含一个没有外部邻居的节点，以及至少一个具有多个邻居的节点。关闭 dropout 后检查：

1. 非邻居权重为零，每个节点每个头的邻域权重之和为 1。
2. 仅有自环时，权重为 1，聚合结果等于自身特征变换。
3. 等权模式与手算的邻居均值相符。
4. 修改邻居特征，观察权重与输出的变化；同一层中，非邻居特征的改变不应直接影响该节点输出。
5. 交换节点编号并同步交换特征、关系后，输出应作相同置换。此项可作为教师演示。

训练时注意力 dropout 后的系数不再要求逐行和为 1。检查与绘图均明确使用 dropout 前的归一化权重，并在评估模式下提取。

### 6.2 训练检查与模型选择

先检查一次全图前向和训练标签掩码，再检查 `backward()` 后的梯度与 `step()` 后的参数变化。可用固定的小组训练节点做短暂拟合检查，不利用验证或测试标签，也不把小样本拟合成功当成泛化证据。

每轮训练使用完整图，一轮对应一次参数更新。训练后切换到评估模式，对同一组固定参数计算训练和验证指标，避免将训练模式下带 dropout 的指标直接与验证指标比较。

实施配置：Adam，学习率 0.005，权重衰减 0.0005；特征 dropout 与注意力 dropout 均为 0.6；统一训练 300 轮。该预算已完成本机 CPU 预跑，学生设备仍需另行计时，不承诺固定准确率或耗时。

按验证准确率选择最佳轮次，相同时选验证损失较低者，再相同选较早轮次。保存独立的参数快照并恢复后评价。三组分别重新训练，不能沿用另一组已经训练过的权重。

主结果使用模型种子 42；备课时用 42、2026、3407 三个初始化种子检查趋势。课堂时间允许时由学生重复，否则提供同配置参考重复结果，明确其来源。固定划分下的重复仅反映初始化与训练随机性，不等同于跨划分稳定性。

### 6.3 注意力观察与边移除

教师固定选择少量验证节点，兼顾不同度数，并避免只展示支持预期的样本。展示完整一跳邻域；邻居过多时可以只画部分，但说明展示范围，不能将截取子图当成完整训练图。

分别查看各注意力头；若展示多头平均值，明确平均方式。真实类别只在事后绘图中使用，不能回流为模型输入。

对训练完成的 C 模型，在评估时移除一个节点的某条非自环关系，比较预测类别与分数变化。无向关系同时移除两个方向，重新计算受影响邻域的 softmax，不重新训练。可与移除另一条较低权重关系比较。

这是固定模型的局部敏感性检查。移除边同时改变邻域归一化，注意力权重也不是完整贡献度或因果解释；一次预测变化不足以证明这条边对模型总体最重要。它与“改变图后重新训练”的拓展实验用途不同。

### 6.4 最终测试与结论

全部配置、轮次和展示规则按训练／验证结果冻结后，对三组预先规定的模型统一进行最终测试；不再根据测试排名追加搜索。报告准确率、Macro-F1、分类别召回率及混淆矩阵，同时记录参数量、训练耗时与设备。

结论按“观察到的事实—可能解释—下一步检验”组织。训练／验证差距、同类边较多或几个注意力例子都不能独自证明模型成功或失败的唯一原因。

## 九、选做拓展

每人最多选择一项，先写假设与固定条件，再运行：

1. **标签数量。** 比较每类 5、10、20、40 个训练标签。选择此项时，在首次训练与测试前单独预留每类 40 个节点作为候选训练池，固定其余验证与测试节点；小训练集逐级包含，未启用的训练池节点保持无标签。仅在这套拓展划分内比较，不从已经查看结果的主实验测试集中抽取新训练标签。
2. **关系缺失。** 以无向边为单位随机移除固定比例的引用关系，保留自环并重新训练；每个比例的图固定，记录随机种子。比较图缺失对性能的影响，不将删边直接等同于错误连接。
3. **注意力头数。** 固定总隐藏维度 64，比较 1、2、4、8 头；改变每头维度以保证拼接后宽度相同，报告性能、参数量和耗时。
4. **GCN 基线。** 教师提供标准 GCN 实现，在相同划分与明确的训练配置下比较。说明 GCN 的归一化聚合与课堂等权模式的区别，不预设更复杂的模型一定更好。

拓展比较主要使用验证集，候选方案和选择规则冻结后再统一测试。标签预算、图结构或模型配置的结论均限定在实际采用的划分与预算内。
