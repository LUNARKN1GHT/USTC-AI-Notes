## 2. 三类常见错误

### 2.1 语法错误

Python 无法理解代码结构，程序还没有真正开始运行。例如：

```python
if score >= 60
    print("pass")
```

缺少冒号会产生 `SyntaxError`。括号、引号不配对和缩进混乱也属于这一类。

### 2.2 运行时错误

代码语法正确，但运行到某个操作时无法继续：

```python
score = "85"
print(score + 5)       # TypeError

values = [10, 20]
print(values[2])       # IndexError

student = {"name": "小科"}
print(student["score"])  # KeyError
```

### 2.3 逻辑错误

程序不报错，但答案不正确：

```python
score = 92

if score >= 60:
    level = "pass"
elif score >= 85:
    level = "excellent"
```

`92` 同时满足两个条件，但程序先进入 `score >= 60`，后面的分支永远不会执行。应优先判断更严格的条件。

## 3. 阅读 traceback

遇到报错时先看最后几行，不要从第一行开始猜。

```text
Traceback (most recent call last):
  File "demo.py", line 8, in <module>
    average = total / count
ZeroDivisionError: division by zero
```

按以下顺序阅读：

1. 最后一行：异常类型是 `ZeroDivisionError`，原因是除数为零。
2. 倒数第二行：真正失败的表达式是 `total / count`。
3. 文件与行号：自己的代码第 8 行。
4. 检查现场：`total` 和 `count` 分别是什么值？`count` 为什么是零？

报错位置是“异常被触发的地方”，不一定是“错误最早产生的地方”。例如 `count` 可能在更早的循环中没有正确累加。

## 4. 一套可重复的调试流程

### 第一步：稳定复现

记录能够触发问题的最小输入。输入不断变化时，很难判断修改是否有效。

### 第二步：分类并定位

- 有 traceback：先看异常类型和最后一个属于自己代码的行号。
- 没有 traceback 但结果不对：把问题视为逻辑错误，比较“期望值”和“实际值”。

### 第三步：检查假设

在关键位置临时打印变量：

```python
print("DEBUG", index, value, type(value))
```

列表和字典还可以检查：

```python
print(len(records))
print(record.keys())
```

平台判题前必须删除调试输出，因为平台要求输出完全匹配。

### 第四步：最小修改

一次只修改一个原因。大段重写会引入新的错误，也无法知道究竟是哪一处修改起作用。

### 第五步：验证

至少测试三类情况：

- 正常情况；
- 边界情况，例如 0、60、100 或空列表；
- 异常情况，例如 `"NA"` 无法转为数字。

## 6. 用函数缩小问题范围

函数把一段任务包装成可重复调用、可单独测试的单元：

```python
def calculate_average(total, count):
    if count == 0:
        return 0.0
    return total / count


average = calculate_average(240, 3)
print(average)
```

### 6.1 参数与返回值

- 参数是函数接收的数据；
- `return` 把结果交回调用位置；
- `print()` 只负责显示，不等于返回结果。

```python
def wrong_add(a, b):
    print(a + b)


result = wrong_add(2, 3)
print(result)  # None
```

要让 `result` 得到 `5`，函数应写成 `return a + b`。

### 6.2 局部变量

函数内部创建的普通变量通常只在函数内部使用。优先通过参数传入数据、通过 `return` 返回结果，不依赖随处可改的全局变量。

### 6.3 一个函数只承担一个清楚的任务

综合题可以拆成：

```text
一行文本 → parse_record() → 合法字典或 None
合法记录 → 累计统计
统计结果 → get_status() → 状态字符串
```

拆分后可以分别测试“解析是否正确”和“统计是否正确”。

## 7. 使用异常处理清洗输入

用户输入、文本文件和平台数据都是字符串。以下转换可能失败：

```python
confidence = float("NA")
```

只捕获预期会发生的异常：

```python
def parse_number(text):
    try:
        return float(text)
    except ValueError:
        return None
```

不推荐：

```python
try:
    # 很长的一大段程序
    ...
except:
    pass
```

空的 `except:` 会把拼写错误、索引错误等真正的程序缺陷一起隐藏。`try` 中只放可能失败的转换，并明确捕获 `ValueError`。

## 8. 用 assert 把预期写进代码

`assert` 后面是一个应该为真的条件：

```python
def clamp_score(score):
    if score < 0:
        return 0
    if score > 100:
        return 100
    return score


assert clamp_score(75) == 75
assert clamp_score(-3) == 0
assert clamp_score(120) == 100
print("✅ 测试通过")
```

测试失败时，不要修改 `assert` 来迎合错误结果；应检查被测试函数。测试应覆盖不同路径，而不是只测一个“刚好能过”的例子。

## 10. 从实数到复数：第一次定义类

### 10.1 为什么要定义类

复数不仅有实部和虚部这两个数据，还具有加法、乘法、共轭和模长等操作。若分别使用两个普通变量，数据和操作容易散落在程序各处：

```python
z1_real = 3
z1_imag = 4
z2_real = 1
z2_imag = -2
```

类可以把“数据”和“操作这些数据的方法”组织到一起。

### 10.2 实数类

先从只含一个属性的实数类开始：

```python
class RealNumber:
    def __init__(self, value):
        self.value = float(value)

    def __repr__(self):
        return f"RealNumber({self.value})"

    def __add__(self, other):
        return RealNumber(self.value + other.value)

    def __mul__(self, other):
        return RealNumber(self.value * other.value)

    def __abs__(self):
        return abs(self.value)

    def to_complex(self):
        return ComplexNumber(self.value, 0)
```

使用方法：

```python
x = RealNumber(3)
y = RealNumber(-2)

print(x + y)   # RealNumber(1.0)
print(x * y)   # RealNumber(-6.0)
print(abs(y))  # 2.0
```

这里的魔法方法并不神秘：

- `x + y` 会调用 `x.__add__(y)`；
- `x * y` 会调用 `x.__mul__(y)`；
- `abs(x)` 会调用 `x.__abs__()`；
- 在 notebook 中查看 `x` 时会使用 `__repr__()`。

### 10.3 复数类

定义复数 `a + bi`：

```python
class ComplexNumber:
    def __init__(self, real, imag=0):
        self.real = float(real)
        self.imag = float(imag)

    def __repr__(self):
        return f"ComplexNumber({self.real}, {self.imag})"

    def __add__(self, other):
        return ComplexNumber(
            self.real + other.real,
            self.imag + other.imag,
        )

    def __mul__(self, other):
        return ComplexNumber(
            self.real * other.real - self.imag * other.imag,
            self.real * other.imag + self.imag * other.real,
        )

    def __abs__(self):
        return (self.real ** 2 + self.imag ** 2) ** 0.5

    def conjugate(self):
        return ComplexNumber(self.real, -self.imag)
```

每个返回复数的方法都创建一个新对象，不直接修改原对象。这使表达式更容易理解和调试：

```python
z1 = ComplexNumber(3, 4)
z2 = ComplexNumber(1, -2)

z3 = z1 + z2
z4 = z1 * z2

assert (z3.real, z3.imag) == (4.0, 2.0)
assert (z4.real, z4.imag) == (11.0, -2.0)
assert abs(z1) == 5.0
assert (z1.real, z1.imag) == (3.0, 4.0)  # 原对象没有改变
```

### 10.4 用断言调试复数乘法

复数乘法公式为：

```text
(a + bi)(c + di) = (ac - bd) + (ad + bc)i
```

建议分别测试容易人工计算的情况：

```python
one = ComplexNumber(1, 0)
i = ComplexNumber(0, 1)

assert (one * i).real == 0
assert (one * i).imag == 1
assert (i * i).real == -1
assert (i * i).imag == 0
```

如果 `i * i` 得到 `1`，应首先检查实部中的减号，而不是重写整个类。

### 10.5 实数与复数的关系

数学上，实数可以看作虚部为零的复数。基础任务采用显式转换：

```python
r = RealNumber(2)
z = ComplexNumber(3, 4)
result = r.to_complex() + z
```

这样规则清楚，也不会突然引入复杂的类型分派。将 `RealNumber` 设计成 `ComplexNumber` 的子类、支持 `2 + z` 等反向运算，可以作为选做题。

## 11. 综合实验：二分类模型预测日志清洗与评估

### 11.1 输入格式

第一行是记录数 `n`，随后 `n` 行格式为：

```text
样本编号 真实标签 预测标签 置信度
```

示例：

```text
S001 1 1 0.92
S002 0 1 0.73
```

### 11.2 数据清洗规则

一条记录满足以下全部条件才有效：

1. 真实标签和预测标签能转换为整数；
2. 置信度能转换为小数；
3. 两个标签都只能是 `0` 或 `1`；
4. 置信度在 `[0, 1]` 范围内。

无效记录计数后跳过，不参与其他统计。

### 11.3 统计规则

- 真实标签和预测标签相同为预测正确，否则为预测错误。
- `TP`：真实为 1、预测为 1。
- `FP`：真实为 0、预测为 1。
- `FN`：真实为 1、预测为 0。
- `TN`：真实为 0、预测为 0。
- 准确率为 `正确记录数 / 有效记录数 × 100`；没有有效记录时为 `0.0`。
- 平均置信度只对有效记录计算；没有有效记录时为 `0.00`。
- 找出置信度最高的错误预测；并列时保留先出现的样本，没有错误预测时输出 `NONE`。

### 11.4 评估状态

- 准确率不少于 80，且有效记录不少于 5 条：`reliable`；
- 否则准确率不少于 60：`usable`；
- 其余：`needs_review`。

### 11.5 固定输出

程序输出七行，不得增加提示语和调试信息：

```text
有效记录数 无效记录数
正确数 错误数
TP FP FN TN
准确率（保留一位小数）
平均置信度（保留两位小数）
置信度最高的错误样本编号
评估状态
```

### 11.6 公开样例

输入：

```text
7
S001 1 1 0.92
S002 0 0 0.80
S003 1 0 0.75
S004 0 1 0.60
S005 1 1 0.88
S006 0 0 bad
S007 2 1 0.90
```

输出：

```text
5 2
3 2
2 1 1 1
60.0
0.79
S003
usable
```
