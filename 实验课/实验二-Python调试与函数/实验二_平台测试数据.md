# 实验二平台自动判题配置

## 判题设置

- 判分依据：根据通过的测试用例数目给分；
- 测试数据：5 组，每组 20 分；
- 输出结果验证：完全匹配；
- 性能判分：关闭；
- AI 判分：关闭；
- 建议第 1 组为公开样例，第 2—5 组为隐藏数据。

学生程序不得输出输入提示、记录明细、调试信息或其他文字。

## 题目规则

每条记录包含样本编号、真实标签、预测标签和置信度。

1. 标签必须能够转换为整数，且只能是 `0` 或 `1`。
2. 置信度必须能够转换为小数，且位于 `[0, 1]`。
3. 无效记录计数后跳过，不参与其他统计。
4. 混淆矩阵顺序固定为 `TP FP FN TN`。
5. 准确率以百分数表示并保留一位小数，平均置信度保留两位小数。
6. 错误预测的置信度并列时保留先出现的样本；没有错误预测时输出 `NONE`。
7. 准确率不少于 80 且有效记录不少于 5 条时为 `reliable`；否则准确率不少于 60 时为 `usable`；其余为 `needs_review`。

固定输出七行：

```text
有效记录数 无效记录数
正确数 错误数
TP FP FN TN
准确率
平均置信度
最高置信度错误样本编号
评估状态
```

## 测试数据 1：公开样例

命令行输入：

```text
7
S001 1 1 0.92
S002 0 0 0.80
S003 1 0 0.75
S004 0 1 0.60
S005 1 1 0.88
S006 0 0 bad
S007 2 1 0.90
```

标准输出：

```text
5 2
3 2
2 1 1 1
60.0
0.79
S003
usable
```
