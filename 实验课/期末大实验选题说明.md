# 期末大实验选题入口

下面的五份材料涵盖数值预测、推荐、图像、文本和交互决策。同学们可以根据兴趣选择材料，自行确定研究问题，最终提交一份实验报告及配套的代码、参数文件。表中的题目和方法供选题参考，具体提交要求见 [大作业要求与相关规则](大作业要求与相关规则.md)。

| 材料说明                                                   | 可以研究的问题                                                     | 对应课程内容                                |
| ---------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------- |
| [共享单车](期末大实验小样/01-共享单车/共享单车数据集.md)   | 根据历史记录预测下一小时的站点借还量，研究邻站信息和历史窗口的作用 | 回归、神经网络、图学习、时间序列与注意力    |
| [短视频反馈](期末大实验小样/02-短视频推荐/短视频数据集.md) | 根据用户和视频信息预测长时间观看，比较不同曝光方式下的表现         | 逻辑回归、表示学习、用户与视频二部图        |
| [卫星图像](期末大实验小样/03-卫星图像/卫星图像数据集.md)   | 识别地表类型，研究模型在新地区或少量标注下的表现                   | 分类、MLP、CNN、泛化与数据增强              |
| [网格导航](期末大实验小样/04-网格导航/网格导航数据集.md)   | 让智能体到达目标，研究专家示范、观测范围和奖励的作用               | 马尔可夫决策过程、动态规划、Q-learning、DQN |
| [IMDb 影评](期末大实验小样/05-文本情感分析/影评数据集.md)  | 判断评论情感，研究少量标注时自监督预训练是否有帮助                 | 词向量、Transformer、掩码预测、预训练与微调 |

五个文档分别解释数据样本、字段、模型输入和目标，并配有可以直接运行的起步脚本。脚本使用小规模样本或简单基线，帮助检查从读取数据到评价结果的完整流程。

## 把选题落实为一个实验

各指南给出了建议任务、关键公式、可比较的因素和参考论文。同学们可以围绕一个具体问题选择方法，再用对照实验检查自己的解释。

| 研究环节   | 可以先确定什么                               | 适合保留的证据                       |
| ---------- | -------------------------------------------- | ------------------------------------ |
| 明确任务   | 输入、预测目标或动作，以及使用时能看到的信息 | 一条样本、输入输出形状和数据划分说明 |
| 建立基线   | 简单方法在同一任务上能做到什么               | 验证与测试指标、典型错误样本         |
| 设计模型   | 哪个模块对应自己的假设，目标函数怎样定义     | 模型结构、关键公式、训练与评价过程   |
| 比较与分析 | 固定哪些条件，改变哪个因素                   | 指标表、学习曲线、分组结果或失败案例 |

## 实验起步

先阅读选中材料的介绍，在该材料目录打开终端，运行下面的命令。各目录都有自己的依赖清单，安装所选材料需要的依赖即可。

```bash
python -m pip install -r starter_requirements.txt
python starter.py
python -m pip install XXXX # 如有其他依赖环境
```

运行后对照实验样例中给出的样本数，确保数据集完全下载，之后再完成相关任务。
