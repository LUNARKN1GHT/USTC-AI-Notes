# 期末大实验选题入口

下面的五份材料涵盖数值预测、推荐、图像、文本和交互决策。同学们根据兴趣选择其中一个题目，按任务介绍完成基础实验，并在开放部分自行确定研究问题，最终提交实验报告、代码、模型与复现配置及支撑结论的运行结果。表中概括了各题的研究主线，具体提交要求见 [大作业要求与相关规则](大作业要求与相关规则.md)。

| 材料说明                                                   | 可以研究的问题                                                     | 对应课程内容                                |
| ---------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------- |
| [共享单车](期末大实验小样/01-共享单车/共享单车任务介绍.md)   | 预测下一小时的站点借还量，研究预测改进能否改善调度效果 | 回归、神经网络、图学习、时间序列与注意力    |
| [短视频反馈](期末大实验小样/02-短视频推荐/短视频任务介绍.md) | 预测长观看反馈，研究模型在常规与随机曝光下的表现及失效原因 | 逻辑回归、表示学习、用户与视频二部图 |
| [卫星图像](期末大实验小样/03-卫星图像/卫星图像任务介绍.md) | 研究地表分类的表示方法，比较区域内与跨地区泛化及类别错误 | 分类、MLP、CNN、泛化与数据增强 |
| [网格导航](期末大实验小样/04-网格导航/网格导航任务介绍.md) | 从专家示范学习动作，研究策略在自主导航中的表现及失败原因 | 模仿学习、部分可观测决策；可扩展规划与强化学习 |
| [IMDb 影评](期末大实验小样/05-文本情感分析/文本情感分析任务介绍.md) | 研究文本表示与少标签分类，分析语言现象及可选的自监督迁移 | 文本分类、词向量、Transformer、预训练与微调 |

五份任务介绍分别说明必做、建议完成与选做安排，并链接到数据集说明与可直接运行的起步脚本。数据集说明解释样本、字段、模型输入和目标；脚本使用小规模样本或简单基线，帮助检查数据读取、评价或训练批次。

## 选题完成与研究深度

各选题的前两部分为必做，用于基础得分评定；第三部分为“建议完成”，适合追求高分的同学，其难度相较前面没有显著提升，建议在前两部分基础上继续完成。第四部分为选做，适合追求满分或对相关内容感兴趣的同学进一步探究。列出的方向供参考，也欢迎自行提出其他有价值的问题与想法。

评分根据工作量与质量综合评定，**高质量地完成前三部分已经可以获得高分**。具体评分维度见 [大作业要求与相关规则](大作业要求与相关规则.md)。

## 把选题落实为一个实验

各指南给出了建议任务、关键公式、可比较的因素和参考论文。同学们可以围绕一个具体问题选择方法，再用对照实验检查自己的解释。

| 研究环节   | 可以先确定什么                               | 适合保留的证据                       |
| ---------- | -------------------------------------------- | ------------------------------------ |
| 明确任务   | 输入、预测目标或动作，以及使用时能看到的信息 | 一条样本、输入输出形状和数据划分说明 |
| 建立基线   | 简单方法在同一任务上能做到什么               | 验证与测试指标、典型错误样本         |
| 设计研究   | 哪种特征、模型、训练或决策设计能够回答问题，评价怎样对应目标 | 方法依据、关键公式、训练或拟合与评价过程 |
| 比较与分析 | 哪些共同条件与变化因素需要说明，怎样检验自己的解释 | 与问题匹配的指标、曲线、分组结果或案例 |

## 实验起步

先阅读选中材料的介绍，在该材料目录打开终端，运行下面的命令。各目录都有自己的依赖清单，安装所选材料需要的依赖即可。

```bash
python -m pip install -r starter_requirements.txt
python starter.py
```

若增加或调整依赖，在提交的环境说明中记录版本与安装方式。

运行后结合材料说明核对数据规模、输入输出和划分，再按所选题目的任务介绍完成前两部分，建议继续完成第三部分，并根据兴趣自主选择第四部分的探索方向。
