# 实验大作业要求

> - 作业时间：2026.11.26 -- 2026.12.10（两周）
> - 个人完成

## 实验选题

助教提供五个选题及对应的数据或实验环境，同学们根据兴趣选择其中一个，按任务介绍完成实验，并在开放部分确定自己的研究问题。各选题的具体任务见 [期末大实验选题入口](期末大实验选题说明.md)，数据集说明提供字段、代码示例、相关公式与参考资料。

### 任务完成与评分层次

各选题分为四个部分，同学们可结合兴趣与目标安排研究深度。

| 部分 | 完成建议与评分定位 |
| --- | --- |
| 第一、二部分（必做） | 用于基础得分评定，完成数据处理、基线建模和自主对照研究，充分体现自己的思考与分析。 |
| 第三部分（建议完成） | 适合追求高分的同学。在前两部分基础上进一步评价与诊断，难度相较前面没有显著提升，建议完成。 |
| 第四部分（选做） | 适合追求满分或对相关内容感兴趣的同学进一步探究。材料列举了一些参考方向，也欢迎自行提出其他有价值的问题与想法。 |

评分根据实际工作量与完成质量综合评定。**高质量地完成前三部分已经可以获得高分。** 第四部分鼓励开放性思考与深入研究，完成情况结合问题价值、实验设计、分析深度和证据质量评定。

第二、四部分列出的方向供参考，可以自行提出与选题相关、有价值的问题。根据研究问题安排合理的实验规模与深度，可以使用固定数据子集、小型模型或简单方法，并说明选择依据、数据规模和计算条件。已有实验可以在不同部分复用，报告中说明它们分别回答了什么问题。

数据或场景的划分应与研究问题匹配。方案调整与模型选择使用训练、验证或独立开发部分，测试部分用于确定方案后的最终评价；若根据测试诊断继续修改方法，应重新安排开发与最终评价数据或场景。

## 打分说明

两位助教分别独立打分。分差较小的情况下直接取平均，若分差较大会有第三次批改。

我们希望锻炼同学们理解任务、处理数据、建立模型、设计实验和分析结果的能力。评分综合考虑实际工作量与质量，重点看研究问题是否清楚、设计是否有理由、对照是否公平、结论是否有证据支持。模型复杂度、实验数量和最终指标结合具体问题评价；简单方法或未取得提升的实验，也可以通过扎实的设计与分析体现价值。报告需要展示研究过程、对照与证据。

| 维度               | 具体内容                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------- |
| 任务理解与数据处理 | 输入、目标与可用信息明确；预处理有依据；划分与数据或环境特点匹配；正确安排训练、选模与最终评价 |
| 基线与研究设计     | 按选题要求建立简单参照与可训练基线；研究问题或假设清楚；特征、模型、训练或决策设计有依据；目标与评价相匹配 |
| 对照实验与分析     | 对照能够回答研究问题；共同条件与变化因素清楚；数据、信息或计算预算的差异有说明；指标、图表与案例支持结论 |
| 工作深度与完成质量 | 已完成部分形成完整实验；进一步评价或开放探索有实质内容；能分析适用条件、失败现象与代价 |
| 复现与交付         | 数据清单、预处理、参数、配置和随机种子可追溯；保留支撑报告结论的运行结果；提供运行与结果生成说明 |
| 表达与规范         | 结构清楚；公式与图表服务于解释；引用现成方法与代码；说明 AI 辅助及本人完成的工作 |

### 报告中需要回答的问题

1. **问题与任务**：选择了哪个题目，完成了哪些部分？输入、预测目标或动作是什么，使用时能够获得哪些信息？自主研究的问题或假设是什么，为什么值得研究？
2. **数据与实验设置**：怎样检查、整理和处理数据，依据是什么？怎样安排训练、验证和测试数据，或训练与评价场景？特征与样本如何构造，输入和输出是什么？使用了多少数据、哪些额外语料或预训练资源？
3. **基线与方法**：基线如何建立，自己的方法为什么适合研究问题？关键特征、表示、训练目标或决策规则起什么作用？哪些部分沿用已有实现，哪些设计、实验与分析由自己完成？
4. **对照与证据**：比较哪些方案，保持哪些共同条件，改变了什么？研究某个因素时，怎样尽量排除其他因素的影响？若整体方案有多处差异，怎样通过补充对照或分析解释结果？结合问题选择指标、曲线、分组结果或具体案例。
5. **结果与讨论**：结果是否支持假设，哪些现象与预期不同，方法适用于什么条件？完成第三、四部分时，分别说明进一步评价和开放探索回答了什么问题。结论与实际观察对应，并说明影响判断的具体限制。

## 说明

1. 允许使用 AI 辅助讨论思路、编程、排错和表达。**请不要将整份作业交由 AI 完成。** 个人完成要求同样适用于研究问题的选择、实验判断和结果解释；同学们应理解所提交的方法与代码，亲自运行、检查实验，并在报告中体现自己的思考。简要说明 AI 辅助的环节及本人完成的工作，评分依据实际体现的研究与分析质量。
2. 欢迎调研并复用现成的方法、模型和代码。说明其来源、作用及与任务的关系，并体现自己在问题选择、数据处理、实验设计或结果分析上的工作。是否修改模型结构或代码由研究问题决定；复用已有实现时同样需要实际训练或拟合、评价与对照。使用外部预训练模型或额外数据时，说明来源、已知训练数据及使用方式，并在比较中交代信息与资源差异。
3. 提交内容压缩成 `zip` 文件，命名为 `学号_姓名_大作业.zip`，需要包含：
   - [ ] **实验报告**：一份 PDF，写明完成的任务部分、研究问题、数据与设置、方法、结果和分析。关键实现可以用简短代码或伪代码辅助解释，图表应能对应到实际运行结果。
   - [ ] **代码与运行说明**：数据处理、训练或拟合、评价及结果生成代码；附主要运行命令、Python 与依赖版本。可从各题的 `starter_requirements.txt` 开始，记录自行增加或调整的依赖，并说明数据路径与运行顺序。
   - [ ] **模型与复现配置**：保存报告中主要结果对应的模型参数、拟合统计量或策略配置，以及必要的词表、标准化参数等。保留数据划分或抽样清单、超参数与随机种子，并标明对应哪组结果。固定规则方法说明规则及配置；由数据估计的查表结果也应保存。
   - [ ] **支撑报告的运行结果**：保留报告中指标、图表和案例所依据的预测记录、评价汇总、训练日志或回放轨迹等，附上样本或场景标识及对应实验设置，使主要结果能够追溯和重新统计。按实际研究内容选择必要文件，探索过程中的全部中间文件可自行取舍。请**真实地**保留结果；**任何形式的数据造假会带来严重的评分降低**。
4. 有关于问题情景、任务要求等方面的疑惑可向助教反馈。

## 报告结构建议

选题与完成部分 → 问题与假设 → 数据与实验设置 → 基线与研究方法 → 对照结果与案例分析 → 讨论 → 复现、引用与 AI 使用说明。根据实际完成的部分组织报告，将第三部分的进一步评价、第四部分的开放探索放在相应位置。篇幅不作为评分依据，以把问题、证据及其逻辑关系讲清楚为准。
