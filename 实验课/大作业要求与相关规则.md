# 实验大作业要求

> - 作业时间：2026.11.26 -- 2026.12.10（两周）
> - 个人完成

## 实验选题

助教会提供五份实验材料，同学们可根据自己的兴趣选择数据集或实验环境。材料介绍见 [期末大实验选题入口](期末大实验选题说明.md)。

## 打分说明

两位助教分别打分。分差较小的情况下直接取平均，若分差较大会有第三次批改。

我们更希望锻炼同学们的建模、训练等能力，因此评分不以指标高低为主要依据，而看：设计是否有理由、对照是否公平、结论是否被证据支撑。最终指标低于基线不必然扣分；但只给结果、没有过程与对照的报告不能得高分。

| 维度               | 具体内容                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------- |
| 任务理解与数据处理 | 输入、目标与可用信息的定义；清洗与预处理的依据；划分方式与数据特性匹配；防止信息泄漏      |
| 基线与模型设计     | 至少一个简单基线；每个模块对应一个假设；为什么添加/删除某个模块；目标函数与评价指标的关系 |
| 对照实验与证据     | 固定其他条件、每次只改一个因素；指标表、学习曲线与错误样本                                |
| 复现与交付         | 参数文件、配置与随机种子齐全；报告中的数字复现、回溯                                      |
| 表达与规范         | 结构清楚；公式与图表规范；必要时包含 AI 使用说明                                          |

### 报告中需要回答的问题

1. **模型设计思路**：根据你的选题，你有怎样的思考，为什么要设计这样的模型。中间的各个模块有怎样的用处，为什么要添加/删除某个特定的模块？
2. **数据集的处理**：
   - 对于刚拿到手的数据集，你是怎样清洗数据集的？
   - 基于数据集的特性，你是怎样划分训练集、验证集和测试集的？
   - 数据集划分后，你又进行了怎样的处理，以便后面的训练？
3. **对照实验**：固定了哪些条件，改变了哪一个因素？结果支持什么结论，有哪些结果与预期不符？

## 说明

1. 允许使用 AI 辅助完成实验。**但请不要全部用 AI 完成**，使用 AI 的部分请简单注明。
2. 允许查阅并使用一些现成的模型与设计思路，但在适配选定任务的过程中，还是会需要相应改动的，这里需要体现你的思考与设计。使用现成的模型或代码时，请注明来源（论文、代码仓库链接）。
3. 实验报告压缩成 `zip` 文件，命名为 `学号_姓名_大作业.zip`，需要包含：
   - [ ] **实验报告**：用 `md/ipynb/pdf`。ipynb 需保留运行输出；md 需随附图片。
   - [ ] **代码**：训练与评估脚本（若报告本身是 notebook，可不再单列）。环境以各材料提供的 `starter_requirements.txt`（Python 3.9 及以上）为准。
   - [ ] **模型的参数文件**：格式有很多，包括 `csv/parquet/pt/h5` 等，自行选用即可。请同时说明配置：超参数、随机种子、对应报告中的哪组结果。若方法本身没有可保存的参数（如规则或查表），请说明。

## 报告结构建议

问题与数据 → 划分与预处理 → 基线 → 模型设计与假设 → 实验设置 → 结果与对照 → 讨论与局限 → AI 使用说明。篇幅不作为评分依据，以把问题讲清楚为准。
