# 实验五设计大纲：使用 PyTorch 训练 MNIST 手写数字分类模型

> 讨论稿：承接实验四，以单隐藏层全连接网络为主模型。当前确定教学主线与任务范围；训练参数、耗时和参考结果在制作 notebook 时实测确定。

## 一、实验定位

实验四通过 NumPy 实现正弦函数拟合，让学生亲手完成前向传播、反向传播、梯度检查与参数更新。本次将这些概念迁移到 PyTorch，并完成一个真实图像数据集上的多分类任务。

核心问题：

> 框架替我们计算梯度以后，我们还需要做哪些判断，才能训练出一个结果可信的模型？

实验主线：

> 理解数据与任务 → 建立模型 → 检查一次训练步骤 → 完成小批量训练 → 评估未见样本 → 对照与错误分析

MNIST 的数字图像便于直观检查预测结果，适合作为首次 PyTorch 实验。主模型沿用实验四的单隐藏层结构，让学生集中理解从手写计算到框架训练、从回归到分类的变化。卷积网络留作后续实验或选做。

## 二、与实验四的衔接

| 维度 | 实验四 | 实验五 |
| --- | --- | --- |
| 任务 | 一维正弦函数拟合 | 手写数字 0–9 分类 |
| 输入与输出 | 一个数 → 一个数 | 一张图像 → 十个类别的分数 |
| 数据规模 | 少量人工生成样本 | MNIST 图像数据集 |
| 模型 | NumPy 单隐藏层网络 | PyTorch 单隐藏层网络 |
| 损失 | 均方误差 | 交叉熵 |
| 梯度 | 手写 BP，并用有限差分检查 | 自动求导，理解与手写 BP 的对应 |
| 更新 | 手写梯度下降 | 优化器执行小批量梯度下降 |
| 验证重点 | 计算是否正确、函数是否拟合 | 训练流程是否正确、未见数据上表现如何 |
| 实验方法 | 控制变量、先预测再验证 | 延续上述方法，增加数据划分与错误分析 |

不假设学生已完成实验四可跳过的 PyTorch 演示；本次开头统一补齐必要概念。

## 三、学习目标

1. 将图像、标签、模型输出与张量的形状及含义对应起来。
2. 解释 `nn.Module`、损失函数、自动求导和优化器各自承担的工作。
3. 区分多分类与数值回归，说明为什么输出十个分数，以及交叉熵和准确率的不同作用。
4. 完成并解释一个小批量训练循环，区分 batch、参数更新次数和 epoch。
5. 区分训练集、验证集与测试集的用途，避免用测试结果反复调参。
6. 结合曲线、指标和错误样本判断模型表现，通过受控对照支持结论。

## 四、数据、模型与基础设置

### 4.1 数据

- 使用 `torchvision.datasets.MNIST`，每张图像为 `28 × 28` 的单通道图像，标签为 0–9。
- 从官方训练部分的 60,000 张图像中，固定随机划分 50,000 张训练、10,000 张验证；官方 10,000 张测试图像留到最终评估。
- 教师提供划分代码与固定种子。训练数据打乱顺序，验证与测试按固定顺序读取。
- 初版只将像素转换为 `[0, 1]` 范围的浮点张量，不引入数据增强。
- 先展示样本、标签及一个 batch，再开始搭建模型。

### 4.2 模型

主模型暂定：

```text
图像 (B, 1, 28, 28)
  → Flatten
  → 像素向量 (B, 784)
  → Linear(784, 128) → ReLU
  → Linear(128, 10)
  → 类别分数 logits (B, 10)
```

输出层直接返回 logits。训练时交给 `CrossEntropyLoss`；展示概率时才使用 softmax，预测类别取分数最大的下标。类别标签使用形状 `(B,)` 的整数张量。

对照模型为 `Flatten → Linear(784, 10)`，即线性分类器（softmax 回归）。它提供一个简单基线，用于判断增加隐藏层带来了什么。

### 4.3 初版训练方案

| 项目 | 暂定方案 | 教学考虑 |
| --- | --- | --- |
| 计算设备 | CPU 为基础，GPU 可选 | 必做任务应能在普通学生电脑上完成 |
| 数据精度 | 图像和模型使用 `float32`，标签使用 `long` | 认识数据类型与用途的关系 |
| 优化器 | 无动量 SGD | 与实验四的梯度下降直接对应 |
| 批量大小 | 128 | 引入小批量训练 |
| 学习率 | 0.1，待试跑确认 | 给定起点，避免首次上手就盲目搜索 |
| 训练轮数 | 5–10 个 epoch，待计时后确定统一值 | 为完整训练和一次对照留出时间 |
| 模型选择 | 按验证集表现选择模型与训练轮次 | 测试集只用于最终报告 |

上述参数是备课候选，不是已经验证的性能承诺。正式发放前记录 CPU 耗时和合理结果范围；不把某个准确率设为唯一完成门槛。

| 阶段 | 学生任务 | 核心思考问题 | 完成证据 |

| Q2：认识数据与划分 | 查看数字图像、标签、张量形状及一个 batch | 为什么需要验证集？为什么不能在测试集上选学习率？ | 样本图、形状表与数据用途说明 |

| Q7：最终测试与错误分析 | 冻结选择后评估测试集，展示错分图像 | 高准确率能说明什么？还遗漏了什么？ | 测试指标、错误样本及结论 |

Q1 以简短演示和解释为主，Q2–Q7 为核心操作。各阶段采用“先预测或解释，再运行，再检查”的方式。

### 5.1 自动求导的衔接

复用实验四的小网络例子说明：前向计算仍由模型定义，自动求导根据计算图求梯度，优化器负责更新参数。需要数值比较时直接复制 NumPy 参数，并对齐精度、激活和损失约定。

只讲本实验需要的 Tensor、参数、计算图和梯度，不安排大段 Tensor API 练习。

### 5.2 分类任务的新概念

用一张数字图像解释真实标签、十个分数、概率和最终预测之间的关系。数字类别不是连续回归目标：将“3”预测为“4”不能仅凭数字差较小就认定比预测为“8”更好。

通过教师准备的小例子观察：两个输出可以预测同一类别、准确率相同，但对正确类别分配的概率不同，交叉熵也不同。说明训练使用可微的损失，评价同时关注准确率。

### 5.3 训练循环与检查方法

训练步骤保持可见，让学生补全并解释：

```text
取一个 batch → 清除旧梯度 → 前向计算 → 计算损失
            → 反向求梯度 → 更新参数
```

先检查一批数据，再尝试在几十个固定训练样本上反复训练，观察是否能明显降低损失，最后运行完整训练。小样本拟合用于排查流程，不是泛化能力证据；失败时也要结合学习率与训练预算判断。

评估使用 `model.eval()` 与 `torch.no_grad()`：前者设置模块行为，后者关闭梯度记录，两者作用不同。当前没有 Dropout 或 BatchNorm 的网络在两种模式下前向行为相同，也应建立规范用法。

指标按实际样本数汇总，避免最后一个较小 batch 与完整 batch 被等权平均。若训练曲线采用训练期间的在线指标，要说明其来自不断变化的参数；严格比较最终训练与验证表现时，对同一个固定模型分别评估。

### 5.4 对照与错误分析

基线对照固定数据划分、预处理、batch size、优化器、学习率和 epoch 数，每个模型独立初始化并重新训练。固定并记录随机种子和批次顺序；不同结构的参数形状不同，不宣称它们具有相同初始参数。

这项比较回答“在当前统一训练配置与预算下，增加非线性隐藏层是否改善表现”。它不能证明每个模型都已达到最佳性能，也不能将差异全部归因于激活函数，因为参数量也改变了。

先在验证集比较并选定模型，再加载所选轮次的参数进行最终测试。测试错分样本用于描述结果；若据此提出改进，回到训练／验证流程验证，不能把反复查看后的测试集继续当作独立评估。

## 八、选做拓展

每位学生最多选择一项，先写假设，再做实验：

1. **学习率对照：** 固定模型和初始参数，比较训练速度、稳定性及验证表现，承接实验四。
2. **去掉激活：** 保持两层参数结构与初值，只移除 ReLU，进一步考察非线性的作用。
3. **迁移到 Fashion-MNIST：** 保持输入输出规格，比较不同数据任务的难度，并限定结论范围。
4. **识别自己的手写数字：** 统一尺寸、灰度、前景背景和位置，观察数据分布变化；少量自制样本不能作为总体性能估计。
5. **简单 CNN：** 仅在理论课已覆盖卷积时提供，作为下一次实验的过渡。

## 九、提交与评价

主要提交一个可从头运行的 notebook，包含：

- 数据与形状检查、模型结构、核心训练及评估代码；
- 训练设置、训练／验证曲线、模型选择依据与最终测试结果；
- 线性基线与主模型的对照表；
- 若干错分样本及基于图像的观察，区分观察事实与原因猜测；
- 一次排错记录；使用 AI 时简述关键建议及自己的核验方式。

评价关注训练流程是否正确、测试集是否使用恰当、对照是否有可解释的控制条件、结论是否受到证据支持。不以代码长度或准确率排名代替学习效果评价。
