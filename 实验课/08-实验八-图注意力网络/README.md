# 实验八 · 从自注意力到图注意力网络

实验七在 Cora 引用图上用 GCN 做论文分类，聚合权重由节点的度数决定。这次沿用同一张图与数据划分，先用小图核验点积注意力和图上的邻域掩码，再实现 GAT，让模型学习怎样给邻居分配权重。最后固定训练好的模型，检查删边结果是否支持用注意力权重判断预测对一条边的敏感性。

## 开始实验

1. 在实验八目录中打开 [实验八_学生版.ipynb](实验八_学生版.ipynb)，选择实验七使用的 `ai-lab` 内核。需要补装依赖时，在对应环境中运行 `python -m pip install -r requirements.txt`。
2. 将 notebook、`lab_utils.py`、`requirements.txt` 与 `cora/` 放在同一目录。Cora 随实验提供，可离线读取。模型用 PyTorch 实现。
3. 从头按顺序运行，补全标有题号的 TODO。按各题的记录区留下指定的数值和一句解释。Q4 训练前先写下假设。

## 实验任务

| 题目 | 要回答的问题 | 留下的证据 |
| --- | --- | --- |
| Q1 点积注意力与图掩码 | 同一个节点在全局注意力和邻域注意力中分别能读取谁？ | 节点 0 的一行计算和扰动前后的变化 |
| Q2 手算 GAT | 发送者和接收者的特征怎样进入分数？每个节点的权重在哪些边上归一化？ | 一行加性打分与聚合结果的核验 |
| Q2 拓展 · 改变接收节点，邻居排序会变吗？（选做） | 只改变节点 0 的特征，点积注意力和经典 GAT 会怎样给节点 1、2 排序？ | 两种输入下的权重与排序，以及一句解释 |
| Q3 按边实现多头 GAT | 怎样把小图上的计算搬到 Cora 的边表上？ | 一组节点与注意力头的权重和，以及稠密与按边计算的一致性 |
| Q4 比较三种聚合 | 度数归一化与学习邻居权重分别带来什么变化？ | 双种子验证准确率、同种子差值，以及曲线最佳轮次附近的一条观察 |
| Q5 检查一个节点 | 第一层权重高的边被移除后，预测会改变多少？ | 两次删边的同类概率、带符号变化及预测类别是否翻转 |
| Q6 重复删边检查 | 单节点的观察在更多验证节点上能否重复？ | 配对散点图、汇总数值、一个节点的具体结果及解释 |
| Q7 推理时改用等权（选做） | 固定训练好的 GAT，哪一层改用等权会改变验证集预测？ | 两个种子的验证准确率、相对原模型的预测改变数，以及一个节点的前后对照 |

实验七的划分固定为训练 140 节点、验证 500 节点、测试 2,068 节点。训练损失只用训练标签。本次比较和删边分析都使用验证节点，测试划分留存。课堂按 18:50–21:30 共 160 分钟安排。Q1–Q6 为必做，Q7 为约 25 分钟的选做练习，直接复用 Q4 的模型。

可以用 AI 辅助编码和排错。请在 Q6 记录一条 AI 建议或自己的排错假设，以及相应的检查和输出。例如，用小图检查 softmax 的分组，或验证删除一条引用时两个消息方向都已移除。
