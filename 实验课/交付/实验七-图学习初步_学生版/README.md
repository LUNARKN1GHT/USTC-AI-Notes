# 实验七：图学习初步（学生版）

本实验使用 Cora 论文引用网络，完成节点分类、GCN 与 MLP 对比、标签数量和引用缺失研究，以及一次自主调参。题目与填写位置都在 `实验七_学生版.ipynb` 中；数据格式见 [数据集说明.md](数据集说明.md)。

## 开始实验

1. 解压后保留整个文件夹，在这个文件夹中打开 `实验七_学生版.ipynb`。`lab_utils.py` 和 `cora/` 必须与 notebook 放在同一级。
2. 选用课程所用的 Python 环境。如需安装依赖，在该环境运行 `python -m pip install -r requirements.txt`。
3. 从上到下运行 notebook。遇到 `TODO("题号")` 时，按旁边提示把整个 `TODO(...)` 换成自己的表达式，再继续运行。
4. 将判断、表格和解释直接写在 notebook 对应的题目下方。运行过程中会自动生成 `输出_GCN/` 保存节点划分。

请保留数据集原文件；无需下载 Cora，也无需安装图学习框架。
