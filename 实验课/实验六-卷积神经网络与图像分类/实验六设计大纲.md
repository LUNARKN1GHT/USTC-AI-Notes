# 实验六设计大纲：卷积神经网络与 CIFAR-10 彩色图像分类

> 实施稿：承接实验五，复用 PyTorch 的训练与评估流程，转向彩色物体分类。主实验比较 MLP、CNN 和 CNN 加数据增强；固定像素置乱留作后续拓展。

## 一、实验定位

实验四学习梯度怎样计算，实验五学习怎样完成训练、验证与测试。本次围绕一个新问题：

> 面对彩色图像，怎样根据数据的特点选择模型结构，并用实验判断这种设计是否有用？

继续采用“先预测—运行—检查—解释”的方法。接口查询与代码补全允许使用 AI，课堂重点是理解结构假设、设计对照、核验结果。

## 二、学习目标

1. 区分 RGB 通道、空间维度与类别，解释 HWC、CHW 和 BCHW。
2. 用一次局部计算解释卷积、局部连接与权重共享。
3. 追踪 CNN 中的形状变化，计算参数量，区分参数量、计算量和运行时间。
4. 复用已有训练流程，先检查一批数据与小样本拟合，再完整训练。
5. 比较 MLP 与 CNN，并通过增强对照讨论模型泛化。
6. 根据验证集冻结方案，再用总体指标、混淆矩阵和错分样本解释最终结果。

## 三、数据与训练配置

CIFAR-10 含 60,000 张 32×32 的 RGB 图像，十个类别为飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船与卡车。官方训练部分有 50,000 张，测试部分有 10,000 张。

从官方训练部分固定划分 45,000 张训练池与 5,000 张验证图像，随机种子为 42。提供两种模式：

| 设置 | quick（默认） | full |
| --- | --- | --- |
| 训练图像 | 训练池固定抽取 12,000 张 | 全部 45,000 张 |
| 验证图像 | 固定 5,000 张 | 同一 5,000 张 |
| 训练轮数 | 8 | 12 |
| batch size | 128 | 128 |
| 优化器与学习率 | Adam，0.001 | Adam，0.001 |
| 用途 | 课内完整实验 | 课后或较充足算力环境 |

所有主比较在同一模式内进行。quick 没有使用的训练池样本保持闲置，不转成验证数据。每组独立初始化，模型种子为 42，批次顺序种子为 2026。

预处理先将 uint8 像素转为 [0,1] 浮点张量，再用固定常数逐通道计算 `(x−0.5)/0.5`，得到 [−1,1]。这些常数不从验证集或测试集估计。显示时反标准化并转为 HWC。

默认 CPU、最多 4 个线程；CUDA 或 MPS 可选。参考结果与 CPU 耗时保存在参考答案的实际运行输出中。full 和其他设备的结果需另行实测，不将 quick 耗时直接外推。

## 四、模型

### 4.1 全连接基线

```text
(B,3,32,32)
 → Flatten → (B,3072)
 → Linear(3072,128) → ReLU
 → Linear(128,10)
```

参数量为 **394,634**。它与 CNN 使用同样的彩色输入，避免把颜色差异混入架构比较。

### 4.2 小型 CNN

| 层 | 输出形状 | 可训练参数量 |
| --- | --- | ---: |
| 输入 | (B,3,32,32) | 0 |
| Conv2d：3→16，核3×3，padding=1，stride=1；ReLU | (B,16,32,32) | 448 |
| MaxPool2d：核2×2，stride=2 | (B,16,16,16) | 0 |
| Conv2d：16→32，核3×3，padding=1，stride=1；ReLU | (B,32,16,16) | 4,640 |
| MaxPool2d：核2×2，stride=2 | (B,32,8,8) | 0 |
| Flatten | (B,2048) | 0 |
| Linear：2048→64；ReLU | (B,64) | 131,136 |
| Linear：64→10 | (B,10) | 650 |
| **合计** | | **136,874** |

所有卷积和全连接层包含偏置。最终输出十个 logits，直接使用交叉熵。参考 LeNet 的卷积块与分类层组织方式，这个课堂自拟模型不称为原版 LeNet。

## 五、分阶段任务

| 阶段 | 学生任务 | 核心问题 | 完成证据 |
| --- | --- | --- | --- |
| Q1 彩色图像 | 拆分 RGB 通道，观察样本和形状 | 三个通道是否意味着输出也要变成三倍？ | 通道图、形状和数值范围解释 |
| Q2 卷积与池化 | 手算一个位置，核验小矩阵结果，观察固定边缘滤波 | 为什么滑动时不增加参数？ | 局部计算、输出矩阵与解释 |
| Q3 搭建模型 | 定义 MLP 和 CNN，逐层追踪形状 | 多通道卷积怎样综合输入？ | 两个模型、形状表与参数检查 |
| Q4 训练检查 | 运行一批数据的梯度／更新检查，拟合固定 32 张训练图像 | 小样本拟合能排除哪些问题？ | 损失下降、梯度和参数检查 |
| Q5 模型比较 | 在统一配置下训练 MLP 与 CNN | 结构差异带来什么收益与代价？ | 曲线、验证结果、参数量和耗时 |
| Q6 数据增强 | 对同一 CNN 加入训练增强，保持其他条件一致 | 增强一定能提高准确率吗？ | 图像预览与三组比较表 |
| Q7 最终评价 | 按验证结果冻结选择，最终测试并分析错分 | 总体准确率遗漏了什么？ | 测试结果、混淆矩阵和实验结论 |
| Q8 选做可视化 | 查看已训练 CNN 的第一层特征图 | 观察响应能说明多少内部机制？ | 特征图与结论边界 |

### Q1—Q2：让图像操作对应明确含义

区分颜色通道与类别。通道图用灰度表示强度，并非把 RGB 数值分别当作独立分类任务。标准化的负数不表示物理亮度为负，绘图时需要反变换。

用一个 3×3 小矩阵和 2×2 核说明逐元素相乘与求和，不要求手写完整卷积和反向传播。PyTorch 使用不翻转核的互相关，深度学习通常仍称为卷积。

固定边缘滤波器由教师指定；训练网络的卷积核则根据分类损失更新。不能预设每个学习到的核都对应某种可命名的笔画。

### Q3—Q4：集中检查新结构

学生主要填写模型定义和局部计算，公共训练流程完整提供。保留“形状检查→一批数据→固定小样本→完整训练”的顺序，避免直接运行长训练后再猜问题出在哪里。

小样本检查比较 backward 前后、step 前后的参数，明确求梯度与更新的区别。小样本拟合成功不能保证泛化好，也不能代替数据隔离检查。

### Q5：模型比较的控制与边界

固定数据、预处理、样本顺序、优化器、学习率、batch size 与轮数。每轮在同一组固定参数下评估无增强训练集和验证集；指标按实际样本数汇总。

按验证准确率保存最佳轮次，相同时选验证损失较低者，再持平选较早轮次。独立复制参数，训练完成后恢复最佳状态。

比较回答“这套统一配置与训练预算下，哪个方案更好”。相同轮数不等于相同计算量；两模型还同时改变了深度、参数量和连接方式，不能把结果全部归因于卷积。一次固定种子不构成稳定优势的证明。

计时统一覆盖训练及逐轮评估，记录设备。公共代码对 GPU 做必要同步，不能将参数少直接解释成训练快。

### Q6：数据增强作为一次受控改进

训练增强为反射填充 4 像素后的随机 32×32 裁剪，加概率 0.5 的水平翻转。使用独立的训练视图，共享同一组原始训练索引，避免通过修改共享 transform 污染验证集。

CNN 无增强与有增强保持相同初值、批次顺序、训练预算和超参数。两条训练曲线均在无增强训练视图上重新评估。验证和测试只做确定性预处理。

先预测再运行。增强可能改善泛化，也可能在当前预算下未见收益，或因裁掉关键部分而有负面影响。两种操作共同加入时不能分别归因；翻转是否保持标签需结合任务判断。

### Q7：一次最终测试与证据解释

按三组最佳验证指标冻结方案，才加载测试集。一次遍历同时汇总总体损失与准确率、分类别召回率、混淆矩阵，以及固定顺序的前 12 张错分图。

以“观察到的事实—可能解释—下一步检验”写结论。softmax 分数不是已保证校准的正确概率；几张错分图不足以证明错误原因。测试后提出的改进留待新的训练／验证实验。

保存模型结构名称、最佳参数、类别顺序与预处理约定，便于重建推理模型。保存内容不含优化器状态，不作为精确续训检查点。

## 六、课堂安排与范围

按 120 分钟组织，环境和数据课前准备：

| 环节 | 时间 |
| --- | ---: |
| 回顾、RGB 与数据检查 | 15 分钟 |
| 卷积、通道与池化 | 20 分钟 |
| 模型搭建、形状与小样本检查 | 25 分钟 |
| 训练与基线比较 | 25 分钟 |
| 增强对照 | 20 分钟 |
| 最终测试与结论讨论 | 15 分钟 |

教师提供数据划分、训练与评估、参数快照、绘图和最小检查代码。学生完成模型与核心概念练习、运行三组实验并解释结果。课时较短时，可提供 MLP 的同配置参考结果，保留 CNN 的独立训练和增强对照。

不增加 ResNet、BatchNorm、复杂调度或卷积反向传播推导。Adam 在本实验中作为给定优化器，不另开优化器比较。CNN 也不被描述为天然具有严格平移不变性，边界、下采样与全连接分类头均可能改变平移行为。

## 七、拓展与评价

必做之后可选一项：观察第一层特征图；只用裁剪或只用翻转进行消融；换随机种子检查趋势；在相同条件下比较 CPU/GPU；用同一空间置乱作用于所有图像及 RGB 通道，重新训练以研究邻近关系的作用。

提交可从头运行的 notebook，包含模式、设备、配置、形状与参数检查、三组验证比较、最终测试与解释。允许 AI 辅助，但需给出关键建议的核验方法。评价关注实现、控制条件和证据，不设“必须超过某个准确率”的门槛。
