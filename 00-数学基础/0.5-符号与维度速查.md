# 符号与维度速查

## 通用约定

| 符号 | 含义 |
| :-- | :-- |
| $x$ | 单个输入样本或状态 |
| $y$ | 标签或目标输出 |
| $\theta$ | 模型全部可学习参数 |
| $w,b$ | 权重与偏置 |
| $\mathcal D_{\text{train}}$ | 训练集 |
| $\mathcal L$ | 单样本或小批量损失 |
| $\nabla_\theta\mathcal L$ | 损失关于参数的梯度 |
| $\eta$ 或 $\alpha$ | 学习率 |
| $\lambda$ | 正则化强度 |
| $\mathbb E[X]$ | 随机变量 $X$ 的期望 |

粗体或大写字母通常表示向量、矩阵或随机变量，但不同领域习惯并不完全一致。因此每篇笔记首次出现新符号时，仍应就地定义。

## 机器学习常见形状

| 对象 | 典型形状 |
| :-- | :-- |
| 小批量输入 $X$ | $B\times d_{in}$ |
| 全连接层权重 $W$ | $d_{in}\times d_{out}$ |
| 全连接层输出 $XW+b$ | $B\times d_{out}$ |
| 序列表示 | $B\times n\times d$ |
| 图节点表示 $H$ | $N\times d$ |
| 邻接矩阵 $A$ | $N\times N$ |
| 分类 logits | $B\times K$ |

$B$ 是批量大小，$n$ 是序列长度，$N$ 是节点数，$d$ 是表示维度，$K$ 是类别数。

## 强化学习常见符号

| 符号 | 含义 |
| :-- | :-- |
| $S_t,A_t,R_{t+1}$ | 时刻 $t$ 的状态、动作及随后获得的奖励 |
| $\pi(a\mid s)$ | 状态 $s$ 下选择动作 $a$ 的概率 |
| $\gamma$ | 折扣因子 |
| $V^\pi(s)$ | 策略 $\pi$ 下的状态价值 |
| $Q^\pi(s,a)$ | 策略 $\pi$ 下的动作价值 |

## 写公式时的检查顺序

1. 每个符号是否在首次出现时定义？
2. 矩阵乘法的内部维度是否一致？
3. 求和或 Softmax 沿哪一个轴进行？
4. 期望是对数据、动作、状态转移还是模型随机性求取？
5. 标量损失最终是否能对全部可学习参数求梯度？
